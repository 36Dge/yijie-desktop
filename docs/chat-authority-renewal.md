# 聊天授权续期与页面连续性

2026-11-08 审计，2026-11-09 实现验证，基线 `bf12d3d`。本次由用户要求重新审计并调整权限投影及其页面交互实现。

## 边界与兼容

`contract-impact = semantic`。Desktop 私有 IPC 增加受原生验证的上下文续期，既有
bind / logout / 权限变更的撤销语义不变。Owner、producer 和 consumer 均为 Desktop；
权威源为 `src-tauri/schemas/chat-ipc-v1.schema.json`（schemaVersion 1）及本文。
HTTP、Agent Host、Runtime、持久化格式、业务权限和审批语义不变，Contracts PR/pin 为
N/A（不涉及公共 wire）。旧 renderer 配新 native 仍使用原 bind；新 renderer 与 native
须作为同一应用升级，新增 command 不支持仅热更新 renderer 到旧 native。回滚整套
Desktop 即恢复旧重绑行为，无数据迁移或历史重放。

## 审计与调整

- 原 `authorityKey` 包含 `expiresAt`，普通投影续期导致 dispose/bind、清空页面、订阅
  及原生观察。稳定授权范围使用租户、授权版本、完整能力集合；有效期单独管理。
- `chat_renew_context_v1` 请求为既有 command envelope，加 `payload.tenantSelector`；
  响应复用 boundContextResponse。renderer 不能提交期限、权限、身份或授权版本。
- 原生从现有可信认证适配器重新读取投影，在提交时重新取时间；只续期仍有效且进程、
  租户、授权版本、完整能力集合一致的原 contextId。期限不超过新投影期限或当前时间
  后 300 秒；不恢复过期、注销或被重绑替换的上下文。更高版本使旧授权失效。
- 续期不增加 bind generation，不启动/恢复任务，不清除订阅、游标、审批、附件或
  产物缓存。显式 bind、身份切换和 logout 仍使在途续期无效；晚到响应不能复活页面。
- renderer 在上下文到期前 30 秒尝试续期，合并并发续期。成功只更新上下文期限；
  当前消息、问答输入、焦点、滚动、附件和预览不重建。暂时不可用时在旧期限内
  有界重试；真实拒绝或到期立即清理授权，沿用已有恢复入口。
- 权限投影单独设置硬到期计时器，刷新在途不能取消此边界。临时不可用可以在仍有效
  的旧投影期限内重试；拒绝、无效投影、切换身份及到期不能沿用旧权限。
- 问答保留逻辑继续用于显式重绑的重新确认，不把它当作普通续期的必经流程。

## 验证范围

定向测试，并核对页面输入节点、焦点及阅读状态在普通续期下保持。原生编译只使用
项目标准 Cargo 输出，不覆盖已发布/签名的应用。遵守 `scripts/test-safety-exclusions.json`，
不运行全量回归，不执行强杀、权限破坏、二进制替换或攻击注入。实际结果在完成后记录。
