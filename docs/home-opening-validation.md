# 首页「开界」实现与验证（2026-09-10）

`contract-impact = none`：仅首页品牌展示、文案与进入页面时的播放时机发生变化。任务及权限操作、API/Agent Host 通信、本地持久状态均无契约变化。

## 实现

- 首页使用 `ChatHomeOpening`，2200ms 开场，160ms 交互收尾；32px / 40px 标题、14px / 22px 描述、80px Logo 峰值、32px 静态 Logo。
- 每次从其他页面或任务会话切回空白的“新建任务”首页播放一次；同页重复点击菜单不重播。移除应用生命周期内只播一次的标记，不通过重新创建整个任务页面触发重播。路由为无障碍自动聚焦标题时继续播放，实际聚焦输入框、按钮等控件才收尾。
- 时间 token 同时识别 `ms` 与 `s`：生产构建把 `2200ms` / `160ms` 压缩为 `2.2s` / `.16s` 后，仍按 2200ms / 160ms 执行，避免误读为 2.2ms / 0.16ms。
- 直接读取现有品牌 SVG 的三个路径，细分贝塞尔曲线后做透视投影，以 SVG 曲线绘制每帧外轮廓和连续侧壁，避免缩放低分辨率遮罩以及多层位移边缘。
- 使用应用主题 token；减少动态效果、已有草稿、页面隐藏、组件卸载均有静态承接。动画完成后没有持续动画帧。
- 只更新现有首页标题区和新任务 placeholder，未迁入演示页面中的导航、示例行或预览控件。
