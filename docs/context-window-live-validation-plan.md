## 用例与判定

1. Kimi 短对话：发送“这是上下文用量验收，请只回复：第一轮完成。不要调用工具。”
   再发送“请只回复：第二轮完成。不要调用工具。”记录原生最近一次用量、有效容量、
   turn 身份和界面显示；不以累计 Token 判断。验证新统计更新，不额外轮询模型。
2. 在空闲时切换 MiniMax：切换期间及新统计到达前，旧 Kimi 数值必须撤掉。
   发送“这是模型切换验收，请只回复：模型切换完成。不要调用工具。”，核对新模型
   的原生容量与用量，仍只采信同一原生事件。
3. 切回 Kimi：旧 MiniMax 数值必须撤掉。在验收聊天中明确请求原生 `new_context`
   一次，检查 contextCompaction 开始/完成、公开状态行和窗口 epoch，核对新窗口
   用量刷新及旧样本不复活。绝不把 new_context 结果声称为模型已生成摘要。
4. 浮层保持打开时检查更新；切换聊天再返回，确认无跨聊天或迟到响应污染。
