# 组件尺寸统一与工作流布局修订

2026-09-08。依据用户提供的三张截图及“配色不变，统一、规范、生产级视觉”的要求实施。

`contract-impact = none`：仅变更前端组件几何、排版和展示结构；无 DTO、API、Tauri command、Runtime、权限、持久化或重放边界变化。工作流仍为 FEAT-151 的本地静态展示页，不新增创建、执行、分类、排序或视图切换功能。

## 原因与实施

此前同类尺寸不统一：店铺 YjTabs 为 32px，工作流筛选为 40px、顶部分类为 48px；店铺说明标签为 32px，工作流标签依靠内容和 padding 撑高，Naive UI 状态标签另用默认尺寸。

现统一为：

- 筛选胶囊和紧凑工具按钮 32px，14px 文字，水平 padding 12px，图标 16px。
- 常规操作与确认按钮 36px；明确的大操作保留 40px 档。
- 说明、来源、分类、状态标签固定 24px，12px 文字，水平 padding 8px。
- 一个共享 token / CSS 几何入口，同时映射 Naive UI Button/Tag；页面继续控制原有颜色和交互。

覆盖 Store、Workflow、Skills、Settings，以及 Chat 的权限入口、审批/对话框操作、Artifact 操作/状态、工具身份和图表模式标签。树行、正文链接、媒体点击区、原生视频控件等独立交互类型不套用筛选胶囊。

工作流页面改为：

- 统一标题栏与工具栏基线，创建入口移到“我的工作流”标题右侧，移除占据一整格的大空白创建卡。
- 我的工作流与推荐工作流共享 2/4 列栅格；标准窗口 2 列，可用内容宽度达到 1120px 后 4 列。
- 已有工作流卡为同高 224px 起，图标/分类同排、标题与说明分层、修改时间贴底。
- 推荐卡使用均衡标题换行、编号与输入/处理/输出标注、40px 图标节点和连续连接线，底部使用量与操作对齐。
- 窄窗口顶部分类排成 5+4 项，避免“更多”孤立成行。

正式尺寸说明见 `docs/design/docs/design/04-components/10-component-sizing.md`；相关组件文档与 FEAT-151 Pattern 同步修订。参考 exports 同步几何与主题适配。

## 颜色保护

直接比较修改前后的所有 `--yj-color-*` 声明，亮/暗两套颜色值完全一致。分别生成新旧 Naive UI 主题并逐字段比较，变化仅为高度、字体尺寸、内边距、图标尺寸和圆角；所有颜色、边框颜色、阴影字段一致。

各业务组件保留原有文字、背景、边界和状态色角色。没有新增色板、渐变、品牌装饰色或投影。之前确认的浅灰侧栏选中态与黑色 composer 焦点边框保留。
