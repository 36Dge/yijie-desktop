# 图片产物展示审计与修复

本轮范围：复查 2026-11-11 对图片展示、标题、菜单、复制下载、查看器、缩放、加载动画及后续视觉调整的要求。

`contract-impact = none`。本轮只修改前端布局、焦点、缩放事件及 tooltip 挂载位置；Desktop IPC、API/Agent Host、原生权限、复制/保存实现、本地持久化与重放均不变。原生复制接口的此前 additive 变更仍见 FEAT-128 pattern，本轮没有增加原生接口或依赖。

## 发现及修复

| 问题 | 证据 | 修复 |
| --- | --- | --- |
| 横图的更多按钮落在图片右侧空白区域 | 1180×760 视口、100% 缩放下，图片为 440×247.5，外框为 760×247.5；按钮右缘在图片右缘之外 312px | 在外框上限制最大宽度，使用随图片收缩的块布局；图片、预览按钮和定位框共享实际尺寸。修复后右、上内距均为 8px |
| 横图右侧圆角没有裁到实际图片上 | 外框圆角位于 760px 处，图片实际止于 440px | 外框与图片同宽，图片自身继承圆角 |
| 鼠标打开菜单后 Esc 不可靠 | 菜单打开时焦点仍留在对话正文，键盘事件未进入菜单 | 指针打开时聚焦菜单容器；方向键进入可用项，Esc 关闭并归还触发按钮，引用项继续禁用 |
| 查看器 Tab/Shift+Tab 可越出弹窗 | 原先手写首尾处理，且关闭、刷新按钮未显式声明 tabindex | 启用已有 Naive UI 焦点约束，采用其支持的 div 容器，并给可操作按钮显式 tabindex；实测循环为关闭→刷新→图像区域→关闭，反向也保持在弹窗内 |
| 200% 下 tooltip 重复缩放并越界 | 修复前“刷新预览”气泡宽 256px、左坐标 1954px，超出 1180px 视口 | 图片的三个 tooltip 显式挂载到 body，复用现有门户缩放补偿；同一状态下恢复为 128×56px，横向范围 994–1122px。其他 YjTooltip 保留原默认挂载规则 |
| 细小滚轮位移被逐次取整丢弃 | 每次 deltaY=1 时，缩放反复被取整回 100% | 内部保留连续缩放值，仅展示百分比时取整；10 次普通 1px 位移可累计到 98% |
| WebKit 捏合入口缺失 | 原先只监听 wheel | 补齐 gesturestart/change/end，按手势起点缩放；保留标准 wheel 路径。使用普通手势事件用例验证 70%、150%、300% |
| 刷新期间焦点丢失，之后 Esc 可能无效 | 原生 WebKit 刷新时禁用按钮，焦点退回 HTML；弹窗关闭了库自身的 Esc 处理 | 刷新意图显式保留按钮焦点，加载期间用 aria-disabled 表示忙碌且沿用单次请求保护；启用弹窗自身的 Esc。实机刷新后焦点留在刷新按钮，Esc 正常关闭并回到图片 |

捏合的 `scale` 以手势开始时的距离为基准，采用 [Apple GestureEvent 文档](https://developer.apple.com/documentation/webkitjs/gestureevent/1634533-initgestureevent) 定义的语义。

## 原要求逐项复核

| 要求 | 本轮结果 |
| --- | --- |
| 直接展示图片，移除元数据外壳 | 保持；实机横图与竖图均无格式、大小、来源、就绪标签和常驻保存按钮 |
| 图片标题 | 保持安全文件名去扩展名规则；通用 generated-image 名称回退为“生成的图片”，不从图片内容虚构标题 |
| 更多按钮在图片右上角、透明底 | 已修复定位；8px 内距随界面缩放同步。2026-11-12 用户追加要求移除描边，普通、悬停及展开状态现均无边框，保留键盘焦点提示 |
| 三项菜单 | 顺序为引用、复制、下载；引用按要求禁用，未接接口 |
| 复制图片与下载图片 | 实机横图复制成功使用统一 toast；系统保存面板下载成功，文件为 JPEG 2048×1152、247570 字节 |
| 取消下载静默，不在图片下方插入反馈 | 单元用例确认无新增 toast/内联提示；图片操作的成功与失败继续走 NMessageProvider |
| 点击图片为手型并打开大图 | 保持手型；实机可打开真实横图，比例正确 |
| 查看器右侧只保留刷新 | 保持；关闭在左，刷新在右，弱化图标、悬停底纹和无箭头提示均保留 |
| 图片缩放与比例显示 | 支持 10%–400%；实机 70% 与刷新、浏览器 200% 后拖动均正常。拖动后 scrollLeft 从 433 到 583，松开后结束拖动状态 |
| 生成加载动画 | announced/generating/processing/transferring 均有占位；200% 界面缩放下占位为 420×420 物理像素，即 210×210 CSS 像素。失败、取消和过期不继续播放加载动画 |
| 可访问性、焦点及异步释放 | 菜单 Esc、查看器正反向焦点循环、刷新后关闭、上下文切换、旧预览响应/解码事件、关闭重开、重复操作均有针对性检查 |

## 验证范围与结果

- 9 个相关测试文件：68 项通过、2 项安全排除。覆盖图片、产物列表/外壳、回答组合及操作、tooltip、已有原生客户端与私有契约消费。
- 修改文件 ESLint、vue-tsc 和 `git diff --check` 通过。
- 真实浏览器布局矩阵：5 种图片比例 × 5 档界面缩放 × 2 种布局，共 50 组全部通过。宽列为普通标题/亮色；窄列为长标题/暗色。缩放为 80%、100%、120%、160%、200%，图片为横图、竖图、方图、超宽图及小图。
- 多图在 100% 和 200% 下额外检查，每张图片的按钮均距自身右上角 8 CSS px；200% 菜单为 480×252 物理像素且完整位于视口内。
- 原生客户端实测真实横图按钮位置、菜单、复制 toast、保存、Tab/Shift+Tab、70% 缩放、刷新及 Esc 焦点归还；沿用当前开发客户端 HMR，没有重启或强制结束进程。
- 复现页位于 `tests/visual/chat-artifact-images/`。其中图片是普通本地合成 SVG，操作使用内存客户端；该页用于布局和交互检查，原生写入另由上述实机检查证明。

## 未执行及边界

- 按用户长期安全条款，跳过 DOM 事件处理器注入和恶意预览 URL 用例；其攻击抵御结果不作通过声明。
- 本轮未运行原生测试、全量回归或发布检查，未修改原生代码。
- 生成动画用普通本地生命周期状态验证，未重新发起付费生图。
- WebKit 捏合事件逻辑有普通事件单元覆盖；没有用自动化伪装为真实双指触控板硬件验证。
- 标题仍依赖上游文件名；已有通用名称使用既定回退。引用接口和输入框图片粘贴未在本轮新增，分别遵循原先的延期要求与现有输入能力边界。
