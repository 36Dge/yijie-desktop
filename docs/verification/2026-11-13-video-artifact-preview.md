# 视频与图片预览复查

`contract-impact = none`。本次只改变前端展示、解码资源的内存复用和生命周期。
Desktop IPC、API/Agent Host、原生权限、CSP、原生读取预算、持久化及重放语义保持；没有新增接口、依赖或跨仓修改。
复用既有视频 open/release/save 以及图片 open/release/copy/save 客户端。

## 发现的原因与修复

| 原因 | 修复 |
| --- | --- |
| 视频封面与播放器共用一个被不断替换的状态，开窗、关窗都调用 replacePreview | 分离封面与播放器，保留同一个视频元素和仍有效的句柄；关闭只暂停，重开保留播放位置 |
| 切换任务卸载组件，已解码图片和视频画面被清空 | ChatPage 提供按授权上下文、会话、轮次、产物及内容版本隔离的有界缓存，重新挂载直接复用已解码资源 |
| 图片内联和大图每次各申请一次 one-shot 预览地址 | 移动同一个已解码原图元素，打开大图不重新请求；关闭后原图回到内联位置 |
| 图片 watch 返回新数组，普通展示属性变化也触发 clear/open | 改为逐项监听身份和内容版本，名称/大小更新保持当前预览 |
| 原生最多两个视频句柄，简单保留全部播放器会耗尽预算 | 保留最多两个播放器，按最近使用顺序淘汰；淘汰播放器仍保留小封面，返回任务不触发视频读取 |
| 快速关闭重开时，第一次等待中的打开意图可能重复播放 | 独立的窗口请求序号使旧打开意图失效，新窗口只播放一次 |
| 旧页面迟到的 identity-scoped release 可能撤销新页面的句柄 | 原生预览队列和待完成释放跨页面实例串行，旧释放完成后才申请新句柄 |
| 直接将全部图片改为静态画布会丢失原图渲染特性 | 内联和大图均保留原图元素；只在大图展开期间为被遮罩的原位置绘制静态占位，SVG/支持的动态格式仍由原生图片元素渲染 |

## 最终交互

- 视频卡片只显示真实封面和播放按钮，最大 240×240 CSS px，窄列随容器缩小。
- 播放窗口左侧为关闭、文件名和真实格式/大小，右侧依次为刷新、下载。长标题截断，不挤占按钮。
- 保留 WebKit 原生 controls。关闭暂停，重开继续上次位置；已播放结束时从头开始。
- 切换任务后，缓存内的图片和视频封面直接恢复；仍有效的播放器也复用。
- 主动刷新重新读取一次，视频回到暂停画面；关闭窗口或切换任务不将刷新改成重复请求。准备新资源时保留现有封面。
- 下载独立于预览，仍经系统保存面板保存原件。成功/失败 toast，取消静默。
- 图片仍有原来的标题、更多菜单、复制/下载、缩放、移动、关闭和刷新能力。

## 缓存边界

- 后台缓存最多 24 项、96 MiB 解码画面估算；超限按最近使用顺序淘汰未显示项。显示中的内容仍受原有媒体和解码预算约束。
- 视频仍受原生两句柄限制。播放器超过 4 分钟后，下次播放前更新句柄，早于原生 5 分钟 idle TTL；封面不会因此重新加载。
- 上下文或读取权限变化、离开聊天页面、产物过期、明确的原生权限/不存在/完整性错误会清理对应缓存。权限恢复后只重新申请当前可见的内容。
- 原生 open 和解码串行，解码等待有 15 秒上限，普通失败可重试；没有改变原生资源预算或越过 one-shot/Range 边界。
- 缓存只在本次聊天页面生命周期内持有浏览器元素/画布，不导出像素、不持久化 URL/媒体内容、不写 Pinia/localStorage/文件；重启、离开聊天页面、过期或淘汰后仍会按需重新读取。

- 受影响文件 ESLint、`vue-tsc --noEmit` 和 `git diff --check` 通过。没有运行全量回归或原生测试。
- 真实开发客户端沿既有 HMR 生效。关闭重开保持同一个视频预览地址；从视频任务切到图片任务再返回，地址仍相同，并从原来的 4 秒位置继续播放。未重新生成内容。
- 实机图片大图正常打开、刷新和关闭；切回图片任务直接恢复。浏览器计数页中，视频开关窗口并与图片往返切换后，video open=1、image open=1；主动刷新视频后变为 video open=2，图片仍为 1。
- 实机视频刷新后显示真实画面，下载进入系统保存面板并回报「视频已保存。」。验证文件 `.local/video-preview-20261113/video-cache-review-20261113.mp4` 为 8,838,483 字节，与先前保存的原件 SHA-256 相同。
- 1180×760 验收页检查亮/暗主题、窄列、长标题与 100%/200% 缩放。200% 时视频窗口四边保留 32 个物理像素，标题、元数据、刷新及下载不重叠；180px 窄列中的横图为 360×202.5 个物理像素，原图完整、不变形。
- 视觉页为 `tests/visual/chat-artifact-videos/`，使用普通合成素材和内存客户端，不冒充原生验证；真实原生行为以上述开发客户端检查为依据。临时浏览器页已关闭，视口已复原。
