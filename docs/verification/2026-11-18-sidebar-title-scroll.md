# 长任务标题悬停滚动

`contract-impact = none`：仅调整 Desktop 侧栏任务标题的悬停展示。Desktop 跨进程接口、API / Agent Host、任务导航与权限、会话数据及本地持久状态均不变。

按用户提供的三秒视频观察：超长标题在悬停后向左平移，末尾之后再次接入标题开头。实现采用单行循环滚动，普通状态保留省略号；仅活动且溢出的标题运行，移开、菜单打开或减少动态效果时恢复静止。完整标题保留为唯一可访问名称，不新增文字 tooltip。

侧栏字体与字号需求已按用户要求撤回，导航、工作空间及任务标题沿用原设置；此前对话正文的字体调整保持。

## 实现与验证

- `ChatSidebarSessionTitle` 在活动时测量实际可用宽度，起步延迟500ms、32 CSS px/s匀速循环。两份文字共用同一轨道，通过轨道半宽与半个间隔计算循环终点，避免小数字宽产生接缝。副本设置 `aria-hidden`。
- 非溢出标题不运行。移开、菜单打开或操作进行中恢复省略；重命名重新测量；侧栏/文字尺寸改变时同步；减少动态效果关闭滚动。只为活动行挂载尺寸与动态效果监听，卸载或失活时释放。
- 48项定向组件测试通过：5项新标题行为、33项任务树和10项侧栏用例。覆盖溢出/短标题、移开、重命名、尺寸变化、减少动态效果、快速卸载、菜单暂停与不触发导航，以及原导航/权限/菜单行为。未引入攻击性 fixture。
- 相关文件 ESLint、`vue-tsc --noEmit`、定向 diff 空白检查通过。类型检查首次指出测试中两个 mock getter 的 `this` 缺少标注，补充类型后通过。
- 浏览器真实组件预览：亮/暗、1180×760、100%/140%及200%标题缩放。长标题从静止变为向左平移（实测 transform 到 -144px），移开后副本移除、transform 为 none；菜单展开时无活动动画。只读/项目内任务和顶层任务共用同一标题组件，完整名称在可访问树中只出现一次。
- 侧栏字体回退核验：导航和任务14px、工作空间名称12px，沿用原字体栈；对话正文仍约15px、苹方优先。`YjNavItem.vue`、`YjSidebar.vue` 无本轮差异，侧栏字体临时token已移除。
- 截图、视频参考抽帧和样式观测保存在工作区 `.local/sidebar-title-20261118/`。200%检查限定标题测量/滚动及横向溢出，不将旧预览壳在该倍率的纵向裁切情况视为此次完成的修复。

范围：使用现有Vite热更新与普通本地样例，没有创建真实任务或调用模型，没有重启原生程序、全量前端/原生/后端回归。减少动态效果由组件用例模拟系统偏好验证，未修改用户macOS设置；原生客户端窗口未进行像素级验收。
