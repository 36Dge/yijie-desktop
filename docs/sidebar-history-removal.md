# 移除任务目录后的历史记录展示

日期：2026-09-26

移除本地选定的任务目录后，不再生成“项目已移除”文件夹。原目录的历史任务直接平铺在“任务记录”顶层，位于所有现存项目和托管“任务目录”之后。多个已移除目录的任务一起置于末尾，内部保留来源列表的顺序；置顶任务也不会越过现存目录。

## 实现边界

- `contract-impact = none`：仅调整 Desktop 进程内的侧栏展示投影。API、Agent Host、native IPC、跨版本数据格式和本地持久状态均无变更。
- 使用现有 `projectAvailable` 判断已移除任务，保留 sessionId、projectId、标题、状态及置顶元数据；无数据迁移，回滚不涉及数据转换。
- 项目内任务和顶层任务复用同一行组件，沿用打开、重命名、置顶、删除及权限过滤行为。
- 已存在的历史数据、重新加载和分页追加均使用同一展示规则。
- 本次没有修改 Rust、权限、原生文件操作或用户已有的其他工作区改动。
