# ADR-DESIGN-20260905：清爽青柠、纯白空间与包裹 Logo

## 状态

- 状态：Accepted
- 色彩与品牌基线版本：2.0.0
- 日期：2026-09-05
- 来源：用户明确选择 A「清爽青柠」＋01「纯白通透」，并要求用本次截图 Logo 的 SVG 覆盖既有设计规范。
- 生效范围：`yijie-desktop/docs/design/` 中的颜色、主题、品牌资产及相应参考导出。
- `contract-impact = none`：此次只修改设计文档、文档站与参考导出；活跃 Desktop `src/`、API / Agent Host 协议、Tauri 原生能力和本地持久状态没有可观察变化。

本记录属于设计系统内的视觉决策，2.0.0 是设计基线版本，不是公共 wire 或运行时 API 版本。依照既有版本治理，品牌色变更升级 major；未改动章节继续保留各自的版本与约束。

## 后续决策

2026-09-06 用户确认 [2.1.0 组件配色与状态收敛](./08-component-color-convergence.md)。本记录保留 2.0.0 的历史决策与当时范围；普通组件的 soft/文字/focus/阴影用法以 2.1.0 为准，品牌主色与 Logo 仍有效。

## 背景

用户根据当前页面落地效果认为原有灰绿空间与品牌标志不符合预期，确认使用纯白、青柠、石墨的新组合。Logo 以本次提供的商品包裹 / YJ 负形截图为形态依据，需交付真实 SVG 路径，便于以后页面改造与缩放。

## 决策

| 层级 | 亮色 | 暗色 |
|---|---|---|
| App / 页面 / 导航 | 纯白 `#FFFFFF` | 中性石墨 `#191C20` |
| 卡片 | 纯白 `#FFFFFF` | 石墨 `#25282B` |
| 弹层 | 纯白 `#FFFFFF` | 石墨 `#2E3237` |
| 主文字 | 石墨 `#25282B` | `#F5F7FA` |
| 主操作 / 品牌强调 | 青柠 `#C3F35B` | 青柠 `#C3F35B` |
| 青柠实色上的文字与图标 | 石墨 `#25282B` | 石墨 `#25282B` |

- 以留白、既有间距和细中性边框建立亮色空间层级，不再以大面积灰底或浅绿底承载页面或业务分组。
- 软青柠仅用于局部选中、hover 等交互态。文本型品牌操作与焦点使用可读的深品牌 token，避免浅青柠细字或线条融入白底。
- 暗色使用中性石墨层级，不沿用偏绿背景；默认主题仍跟随系统，light / dark / system 的既有行为不变。
- Logo 统一为商品包裹折面与 YJ 负形。纯矢量资产包含彩色、暗色、单色、横式字标与 App Icon；旧 `yijie-bag-logo.svg` 文件名仅保留兼容用途，内容更新为新标志。
- 成功、警告、错误、信息与 Agent 状态色保持独立语义。图表保留现有系列语义，首序列在亮色使用深品牌图形色、暗色使用青柠，以保证信息边界可读。

## 替代关系与保留范围

当前颜色 token、主题章节、品牌资产、入口文档与 AI 规则覆盖先前关于旧主色、绿色偏色中性色和手提袋 Logo 的规定。历史页面截图与旧验收记录不作为继续采用旧配色的理由。

本次不改变字体、字号、间距尺度、圆角尺度、动效、布局结构、导航信息架构、内容语气、权限、审批或业务状态规则。Logo 参考组件增加可选 `theme` 参数，并明确图形、横版与 App Icon 的变体语义；其他组件 API 与业务交互不变。局部 pattern 仅在原来的背景色差要求或图表首色与本决策冲突时更新色彩条目，其余规则继续有效。未修改既有验收记录，也未将本次文档更新表述为应用迁移已经完成。

## 迁移方式

1. 新需求直接采用当前颜色、主题和品牌规范。
2. 现有页面后续改造时，先将全局 token 与主题映射按参考导出迁入活跃代码，保持 API 与业务状态边界；不得从应用 `src/` 直接导入 `docs/design/exports/`。
3. 替换全局 Logo 使用点并验证亮暗变体、小尺寸和可访问名称；不得以截图或嵌入 PNG 的 SVG 代替路径资产。
4. 逐页检查 App Shell、Chat、我的店铺、工作流、设置以及相关组件的亮暗背景、按钮前景与图表可读性；既有页面布局和交互仍按各自 pattern 执行。
5. AI / Codex 任务使用已更新的 prompt 与规则；此次不修改仓库根 `AGENTS.md`，其中对设计规范的现有引用继续有效。

## 验收标准

- 文档入口、颜色表、亮暗主题、品牌资产与参考导出一致，文档站构建通过。
- SVG 为可缩放路径，公共文档资产与参考导出副本一致；亮色、暗色、单色和小尺寸预览可辨认。
- 亮色背景、导航、卡片均为白色；主按钮以青柠配石墨前景；暗色使用规定的中性石墨层级。
- 文字、焦点、信息性图形按既有可访问性基线检查；青柠不替代独立业务状态语义。
- 变更限定在设计规范目录内，不将文档构建或预览通过扩大为实际桌面应用已迁移、已验收。
