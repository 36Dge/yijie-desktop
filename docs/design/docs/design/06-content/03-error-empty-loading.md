# 错误、空态与加载文案规范


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义错误、空态、加载、同步中、无权限等状态的文案结构。

## 适用范围

适用于界面文案、状态文案、错误文案、按钮、提示、审批、Agent 消息和数据说明。

## 规范正文

## 错误文案结构

错误文案必须包含：发生了什么、可能原因、用户下一步。

示例：

```text
店铺数据同步失败
可能是平台授权已过期。请重新授权后再试。
```

## 空态文案结构

空态必须包含：当前为空的对象、为什么为空、下一步操作。

示例：

```text
暂无已连接店铺
连接店铺后，易界可以为你分析经营数据并执行运营任务。
```

## 加载文案

加载超过 2 秒时显示具体状态，例如“正在读取店铺商品数据”。Agent 长任务不得只显示“加载中”。

## AI / Codex 必须遵守

- 界面文案默认中文。
- 文案必须专业、直接、可执行。
- 不允许夸大 AI 能力或给出不可验证承诺。
- 不允许使用模糊、娱乐化或过度口语表达。

## 实现要求

文案常量可以进入 `src/i18n/zh-CN.ts` 或页面局部常量，但必须遵守统一语气。错误码到文案的映射应集中管理。

## 验收清单

- [ ] 文案为中文。
- [ ] 主操作动词清晰。
- [ ] 错误说明包含解决方式。
- [ ] 风险文案不绝对化。
- [ ] AI 结果没有过度承诺。
