# 文案语气规范


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界 UI 的中文文案语气和表达规则。

## 适用范围

适用于界面文案、状态文案、错误文案、按钮、提示、审批、Agent 消息和数据说明。

## 规范正文

易界文案语气为**专业**。

## 基本规则

- 用短句。
- 先说结论，再补充原因。
- 按用户任务表达，不按系统实现表达。
- 重要风险使用明确提示，不使用含糊词。
- AI 建议使用“建议”“可考虑”“请确认”，不使用“必须”替代用户决策。

## 按钮文案

按钮使用动宾结构：诊断 Listing、连接店铺、重新同步、查看详情、确认执行、取消任务。

## 禁止表达

- “一键爆单”“保证提升销量”“绝对合规”。
- “出错了哦”“稍等一下下”等不专业表达。
- “系统异常”但没有下一步。

## AI / Codex 必须遵守

- 界面文案默认中文。
- 文案必须专业、直接、可执行。
- 不允许夸大 AI 能力或给出不可验证承诺。
- 不允许使用模糊、娱乐化或过度口语表达。

## 实现要求

文案常量可以进入 `src/i18n/zh-CN.ts` 或页面局部常量，但必须遵守统一语气。错误码到文案的映射应集中管理。

## 验收清单

- [ ] 文案为中文。
- [ ] 主操作动词清晰。
- [ ] 错误说明包含解决方式。
- [ ] 风险文案不绝对化。
- [ ] AI 结果没有过度承诺。
