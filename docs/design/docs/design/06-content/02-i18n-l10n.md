# 中文与本地化规范


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界当前国际化范围和中文界面规则。

## 适用范围

适用于界面文案、状态文案、错误文案、按钮、提示、审批、Agent 消息和数据说明。

## 规范正文

当前国际化范围为**中文**。界面文案默认 `zh-CN`，不在首版实现多语言切换。

## 命名规则

- 产品显示：易界。
- 技术名：yijie。
- 品牌缩写：YJ / YIJIE。
- 平台名称按官方中文或常用英文展示，例如 Amazon、Temu、Shopee、TikTok Shop。

## 数字与单位

金额、百分比、时间、件数必须带单位。跨境币种必须显示币种符号或代码。时间显示应明确时区或同步时间。

## 代码准备

虽然首版只中文，代码结构可以保留 i18n 目录，避免文案散落。

## AI / Codex 必须遵守

- 界面文案默认中文。
- 文案必须专业、直接、可执行。
- 不允许夸大 AI 能力或给出不可验证承诺。
- 不允许使用模糊、娱乐化或过度口语表达。

## 实现要求

文案常量可以进入 `src/i18n/zh-CN.ts` 或页面局部常量，但必须遵守统一语气。错误码到文案的映射应集中管理。

## 验收清单

- [ ] 文案为中文。
- [ ] 主操作动词清晰。
- [ ] 错误说明包含解决方式。
- [ ] 风险文案不绝对化。
- [ ] AI 结果没有过度承诺。
