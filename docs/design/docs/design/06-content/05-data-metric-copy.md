# 数据指标文案规范


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义经营指标、广告指标、物流指标和合规指标的命名与解释规则。

## 适用范围

适用于界面文案、状态文案、错误文案、按钮、提示、审批、Agent 消息和数据说明。

## 规范正文

## 指标展示必须包含

- 指标名称。
- 数值。
- 单位。
- 时间范围。
- 同比/环比口径。
- 数据来源或同步时间。

## 示例

```text
广告花费
$1,248.32
过去 7 天 · Amazon 店铺 · 2 小时前同步
```

## AI 解读

AI 解读必须引用指标，不得空泛：

正确：过去 7 天广告花费上升 18%，但转化率下降 6%，建议优先检查高花费低转化关键词。

错误：你的广告效果不太好，建议优化。

## AI / Codex 必须遵守

- 界面文案默认中文。
- 文案必须专业、直接、可执行。
- 不允许夸大 AI 能力或给出不可验证承诺。
- 不允许使用模糊、娱乐化或过度口语表达。

## 实现要求

文案常量可以进入 `src/i18n/zh-CN.ts` 或页面局部常量，但必须遵守统一语气。错误码到文案的映射应集中管理。

## 验收清单

- [ ] 文案为中文。
- [ ] 主操作动词清晰。
- [ ] 错误说明包含解决方式。
- [ ] 风险文案不绝对化。
- [ ] AI 结果没有过度承诺。
