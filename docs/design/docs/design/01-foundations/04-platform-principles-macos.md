# macOS 平台原则


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界作为 Mac 桌面端应用时必须遵守的平台体验原则。

## 适用范围

适用于 Tauri 窗口、导航、快捷键、系统主题、通知、菜单、托盘、文件选择和本地安全能力相关 UI。

## 规范正文

易界桌面端必须具备桌面应用感，而不是简单网页套壳。

## 窗口体验

- 最小窗口尺寸：1180 × 760。
- 推荐默认窗口：1280 × 820。
- 应支持窗口缩放，但核心工作区在最小尺寸下不可破版。
- 侧边栏和右侧面板应有合理收缩策略。

## 系统主题

默认主题跟随系统。用户可以在设置中切换为跟随系统、亮色或暗色，但首版以跟随系统为默认。

## 交互习惯

- 支持常见快捷键：搜索、发送、换行、关闭弹窗、刷新任务。
- 危险操作不能只通过快捷键触发。
- 长任务必须显示进度，不能让用户以为应用卡死。
- 本地文件、下载、导出、通知应使用桌面端语义。

## 系统字体

界面字体使用系统字体栈，不内置第三方字体文件。

## AI / Codex 必须遵守

- 不允许创建只适合 Web 浏览器宽屏的布局。
- 不允许忽略暗色模式。
- 不允许将关键状态只放在网页通知条里，应考虑桌面通知和任务状态。
- 不允许在最小窗口尺寸下隐藏主操作。

## 实现要求

Tauri 相关权限、sidecar 状态、系统通知、Keychain/安全存储等 UI 必须有明确状态反馈。窗口尺寸、布局断点、侧栏宽度写入 token 或常量文件。

## 验收清单

- [ ] 1180 × 760 下页面可用。
- [ ] 跟随系统主题正常。
- [ ] 长任务状态清晰。
- [ ] 桌面端系统能力有反馈。
- [ ] 快捷键不绕过风险确认。
