# 产品上下文


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界桌面端的产品定位、用户场景和界面复杂度来源，避免 AI 将其误做成普通后台或纯聊天应用。

## 适用范围

适用于所有页面、路由、组件、文案、图标、图表和交互模式。

## 规范正文

易界是面向跨境电商卖家的 AI Native 桌面端应用。用户通过易界授权店铺数据与平台权限后，使用 AI 进行选品、Listing 优化、合规检查、广告分析、物流追踪、店铺经营分析等日常经营工作。

易界界面需要同时承载四类任务：

1. **对话型任务**：用户通过 Chat 发起需求，Agent 逐步执行。
2. **数据型任务**：展示店铺指标、广告指标、商品表现、物流状态。
3. **流程型任务**：店铺授权、插件安装、任务审批、结果确认。
4. **高责任操作**：涉及平台权限、广告预算、库存、价格、发布、买家消息等操作。

因此，易界 UI 必须体现“AI 可解释、过程可追踪、结果可操作、风险可控制”。界面不追求装饰感，优先追求清晰、稳定、可信和高效率。

首批核心页面不区分优先级，包括：登录/引导、店铺授权、App Shell、Chat 工作区、Agent 任务详情、Listing 诊断、Listing 优化、广告分析、合规风险、物流追踪、经营分析、插件市场、设置与权限。

## AI / Codex 必须遵守

- 不允许将易界做成通用 Chatbot 皮肤。
- 不允许将易界做成普通 SaaS Admin 后台。
- 新页面必须说明属于对话型、数据型、流程型或高责任操作中的哪一类。
- 涉及 Agent 执行的页面必须展示状态、过程、工具调用和结果。

## 实现要求

路由命名、页面结构和组件抽象必须与产品场景一致。跨境电商领域组件放入 `src/components/yijie/` 或 `src/domain/` 下，不在页面中重复拼装复杂业务 UI。

## 验收清单

- [ ] 页面能看出当前用户在完成什么经营任务。
- [ ] Agent 过程和结果不是黑盒。
- [ ] 高责任操作有确认或审批入口。
- [ ] 页面没有脱离跨境电商上下文的通用模板感。
