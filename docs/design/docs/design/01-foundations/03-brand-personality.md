# 品牌气质

## 目标

定义易界桌面端的视觉性格与表达边界。

## 适用范围

适用于色彩、图标、插画、图表、文案、动效和页面氛围。

## 规范正文

易界的品牌气质为：

1. **专业可信**：像可靠的跨境电商运营专家，而不是娱乐化聊天机器人。
2. **清爽高效**：让用户快速进入任务，不用复杂装饰抢占注意力。
3. **数据驱动**：通过指标、趋势、风险和建议帮助卖家决策。
4. **AI 可控**：AI 能力强，但必须可解释、可审批、可追踪。
5. **跨境经营感**：视觉中允许体现店铺、商品、物流、广告、合规、平台连接等领域感。

视觉组合固定为 **A「清爽青柠」＋01「纯白通透」**。亮色的背景、导航和卡片统一纯白 `#FFFFFF`，主文字使用石墨 `#25282B`。青柠 `#C3F35B` 集中用于品牌识别、主操作与关键选中强调，实色青柠底配石墨文字与图标。留白、间距和细中性边框建立空间层级；不以大面积灰色或浅绿色铺底制造层级。

暗色主题使用中性石墨背景、卡片与弹层层级，保留相同青柠强调；不将整套中性色染绿。成功、失败、警告和 Agent 运行状态使用独立语义 token，品牌青柠不替代这些状态。

Logo 采用用户确认的“商品包裹折面 + YJ 负形”：上部青柠折面暗喻商品包装，左右石墨折面与中间通路组成 YJ 识别结构，关联商品经营与跨境流转。正式使用本规范的 SVG 矢量资产及亮暗、单色变体；不得继续使用旧手提袋轮廓，也不得将截图直接嵌入 SVG 充当矢量。

## AI / Codex 必须遵守

- 不允许使用过度霓虹、游戏、元宇宙、卡通或 3D 视觉风格。
- 不允许把所有按钮和图标都变成青柠色。
- 不允许在白底使用浅青柠小字或白字青柠实色按钮或无层级的大面积浅绿底。
- 不允许在未登记来源的情况下使用平台 logo。
- 不允许将产品名称写成不一致形式，例如 YiJie、YIjie、Ejie。

## 实现要求

产品中文界面统一使用“易界”。代码命名、包名、路由、变量使用 `yijie`。品牌缩写和 Logo 使用 `YJ` 或 `YIJIE`，不得混用其它写法。

## 验收清单

- [ ] 页面气质专业、克制、可信。
- [ ] 纯白空间与石墨阅读层级成立，青柠集中表达主操作和局部强调。
- [ ] 亮暗主题采用对应的 SVG 资产，缩小时包裹与 YJ 负形仍清楚。
- [ ] 产品名称写法统一。
- [ ] 平台 logo 来源可追溯。
- [ ] 未出现不符合 TOB 的装饰风格。
