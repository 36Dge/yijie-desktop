# 品牌气质


## 文档状态

- 状态：Accepted
- 版本：1.0.0-final
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界桌面端的视觉性格与表达边界。

## 适用范围

适用于色彩、图标、插画、图表、文案、动效和页面氛围。

## 规范正文

易界的品牌气质为：

1. **专业可信**：像可靠的跨境电商运营专家，而不是娱乐化聊天机器人。
2. **清爽高效**：让用户快速进入任务，不用复杂装饰抢占注意力。
3. **数据驱动**：通过指标、趋势、风险和建议帮助卖家决策。
4. **AI 可控**：AI 能力强，但必须可解释、可审批、可追踪。
5. **跨境经营感**：视觉中允许体现店铺、商品、物流、广告、合规、平台连接等领域感。

品牌色 `{BRAND}` 源自生长、效率、商业活力的绿色方向。它用于主操作、品牌识别、Agent 正向进展和关键选中态，但不能滥用到所有状态。

Logo 初始方向为“手提袋 + YJ 字母”。手提袋代表电商经营，YJ 代表易界。正式视觉稿出现前，使用本规范生成的 SVG 资产作为工程占位与早期产品资产。

## AI / Codex 必须遵守

- 不允许使用过度霓虹、游戏、元宇宙、卡通或 3D 视觉风格。
- 不允许把所有按钮和图标都变成品牌绿色。
- 不允许在未登记来源的情况下使用平台 logo。
- 不允许将产品名称写成不一致形式，例如 YiJie、YIjie、Ejie。

## 实现要求

产品中文界面统一使用“易界”。代码命名、包名、路由、变量使用 `yijie`。品牌缩写和 Logo 使用 `YJ` 或 `YIJIE`，不得混用其它写法。

## 验收清单

- [ ] 页面气质专业、克制、可信。
- [ ] 品牌色使用有层级。
- [ ] 产品名称写法统一。
- [ ] 平台 logo 来源可追溯。
- [ ] 未出现不符合 TOB 的装饰风格。
