# 易界 yijie Design System / UX 规范

本规范是 `yijie-desktop` 的前端 UX 与设计系统工程标准。它用于指导 AI/Codex 生成 Vue 页面、组件、样式、图标、图表、文案与交互。

## 设计系统定位

易界不是普通后台，也不是纯聊天应用。易界是面向跨境电商卖家的 AI Native 桌面端工具，需要同时满足：

- 桌面端工作台体验；
- AI 对话与 Agent 任务执行体验；
- 电商经营数据分析体验；
- 店铺授权、平台 API、合规风险、广告投放等高责任操作体验；
- 长期由 Codex 参与开发时的 UI 一致性。

2.1.0 收敛正文、图标、控件状态、焦点和阴影，完整定义见 [组件配色与状态矩阵](./04-components/09-component-color-state-matrix.md)。2.0.0 的品牌主色与 SVG Logo 保持不变。字体、间距尺度、圆角尺度、组件结构、导航与交互、文案及安全审批规范继续有效。任何新需求和现有页面的后续改造都应按新基线实现；活跃 `src/` 在正式颜色收敛任务中同步；参考导出仍不是应用运行时依赖，具体运行状态与验证范围以记录为准。

## 文档使用规则

- 设计 token 是唯一样式来源。
- Naive UI 是基础组件库，不等于易界设计系统本身。
- 业务页面应优先使用 `src/components/yijie/` 下的业务组件。
- AI 生成页面前必须阅读对应 pattern 文档。
- 页面新增、组件新增、token 修改都必须通过质量门禁。

## 最重要的 AI 约束

AI/Codex 生成 UI 时必须做到：

1. 不硬编码颜色、字号、间距、圆角、阴影。
2. 不直接从任意图标库 import 图标。
3. 不在页面里临时创造布局系统。
4. 不引入新的视觉风格。
5. 不在没有审批入口的情况下设计高影响操作。
6. 不把产品写成英文界面；界面文案默认中文。
