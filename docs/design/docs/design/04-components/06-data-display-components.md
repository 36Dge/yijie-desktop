# 数据展示组件规范


## 文档状态

- 状态：Accepted
- 版本：2.1.0
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义指标卡、表格、列表、详情、标签、图表卡等数据展示组件。

## 适用范围

适用于 `src/components/yijie/` 下对应组件，以及所有引用这些组件的页面。

## 规范正文

2026-09-08 起，按钮、筛选项和说明标签的尺寸统一遵循[组件尺寸规范](./10-component-sizing.md)，颜色角色保持原规范。

## 必备组件

- `YjMetricCard`：展示核心指标、趋势、环比/同比。
- `YjDataTable`：统一表格行为。
- `YjDescriptionList`：详情字段。
- `YjChartCard`：图表容器。
- `YjStatusTag`：状态标签。

## 规则

数据展示必须明确单位、时间范围和数据来源。空值不能显示为 `null` 或 `undefined`，应显示 `—` 或业务文案。表格操作必须可追踪，批量操作必须显示影响数量。

本类组件的文字、图标、背景、边界、2px 中性焦点、普通容器无阴影与真实浮层轻投影，以 [组件配色与状态矩阵](./09-component-color-state-matrix.md) 为准。readonly 保留正常读值；disabled 只作用于不可用控件；error 与 selected 不能抹掉焦点。现有组件职责、布局与交互不变。

## AI / Codex 必须遵守

- 优先复用现有 `Yj*` 组件，不重复造相同 UI。
- 新组件必须定义 props、slots、状态、空态、错误态和可访问性要求。
- 不允许在业务页面中复制组件内部结构。
- 不允许组件内部硬编码视觉值。

## 实现要求

组件文件使用 PascalCase，例如 `YjMetricCard.vue`。复杂组件应配套 `types.ts`、`README.md` 或文档说明。组件样式使用 token 和 CSS variables。

## 验收清单

- [ ] 组件职责单一。

- [ ] 支持 loading/disabled/error/empty 等必要状态。
- [ ] 可访问性完整。

## 定时任务执行记录

执行记录采用双栏独立卡片，保留数据原有顺序；可用容器不足 720px 时转为单栏。
不增加无来源的日期分组、成功率或记录总数。使用白色／石墨卡片表面、细中性边框、
12px 圆角、20px 内边距、16px 卡片间距，不使用阴影、渐变和装饰性图标底板。

卡片分为三个层级：顶部显示执行时间与文字状态；中间显示 16px 半粗任务标题，
预留两行高度；底部展示触发方式、简化耗时、重新执行及查看对话。通过排版和对齐
组织信息，不使用整行分隔线、彩色状态胶囊或重复的大号成功图标。

已结束、暂停跳过、取消使用中性文字；已结束仅表示执行结束，不表示业务结果成功。
失败、需关注和执行中仍以小范围独立语义文字表达，不铺满卡片。详情同样采用文字
状态，保留五项字段和 520px 宽度。青柠继续用于页面主操作与选中控件。

时间以记录时区显示 `YYYY-MM-DD HH:mm`，完整秒数、时区和偏移保留在悬停提示。
耗时四舍五入到秒，非零且不足一秒显示「不到 1 秒」，悬停提供精确值。未开始项
显示「本次未执行」并省略耗时；未知时间明确标注。需关注的记录保留核对说明。

图标通过 YjIcon 使用同一 Lucide 2px 线宽：RotateCcw 表示重新执行，ArrowUpRight
表示查看对话；不再用彩色图标盒或双气泡装饰。图标只承载动作，保留 tooltip 与
可访问名称。无有效对话不显示对话入口；未执行项不显示重新执行。权限、忙碌、
任务删除及目标不可用时的重跑禁用条件保持。

整个卡片和标题都可打开详情，标题支持键盘操作，关闭详情后恢复焦点；动作与
卡片点击分离。hover/focus-within 仅加强细边框，按钮保留中性可见焦点，无位移。
