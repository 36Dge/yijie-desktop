# 数据展示组件规范


## 文档状态

- 状态：Accepted
- 版本：2.1.0
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义指标卡、表格、列表、详情、标签、图表卡等数据展示组件。

## 适用范围

适用于 `src/components/yijie/` 下对应组件，以及所有引用这些组件的页面。

## 规范正文

2026-09-08 起，按钮、筛选项和说明标签的尺寸统一遵循[组件尺寸规范](./10-component-sizing.md)，颜色角色保持原规范。

## 必备组件

- `YjMetricCard`：展示核心指标、趋势、环比/同比。
- `YjDataTable`：统一表格行为。
- `YjDescriptionList`：详情字段。
- `YjChartCard`：图表容器。
- `YjStatusTag`：状态标签。

## 规则

数据展示必须明确单位、时间范围和数据来源。空值不能显示为 `null` 或 `undefined`，应显示 `—` 或业务文案。表格操作必须可追踪，批量操作必须显示影响数量。

本类组件的文字、图标、背景、边界、2px 中性焦点、普通容器无阴影与真实浮层轻投影，以 [组件配色与状态矩阵](./09-component-color-state-matrix.md) 为准。readonly 保留正常读值；disabled 只作用于不可用控件；error 与 selected 不能抹掉焦点。现有组件职责、布局与交互不变。

## AI / Codex 必须遵守

- 优先复用现有 `Yj*` 组件，不重复造相同 UI。
- 新组件必须定义 props、slots、状态、空态、错误态和可访问性要求。
- 不允许在业务页面中复制组件内部结构。
- 不允许组件内部硬编码视觉值。

## 实现要求

组件文件使用 PascalCase，例如 `YjMetricCard.vue`。复杂组件应配套 `types.ts`、`README.md` 或文档说明。组件样式使用 token 和 CSS variables。

## 定时任务与执行记录

计划卡片以紧凑横排呈现。左侧时间块显示计划时刻与运行频率，启用的计划使用浅青柠底色。中间展示任务名称与摘要，随后为下次执行时间或停用原因及模型标识。编辑和开关位于卡片右侧，历史记录、立即执行和删除入口与它们对齐。

历史、立即执行和删除分别使用时钟、播放三角和垃圾桶。三枚图标共用 24 单位画布、圆端点与圆角连接，显示尺寸为 16px，可见描边宽 1.125px，点击区域为 28px。常态使用次级文字色，悬停和键盘焦点使用主文字色，禁用时使用禁用文字色。空任务列表使用日历插画并提供创建入口。空执行记录使用时间线插画并可返回任务列表。筛选无结果时提供清空筛选操作。

执行记录按数据源顺序逐行排列。执行时间与日期在首列上下对齐，任务名称下方显示触发方式，右侧依次为执行状态、耗时和操作。窄容器将同一条记录折行。长名称最多显示两行，标题按钮提供完整可访问名称。

完成、暂停跳过和取消采用中性文字。失败、需关注和进行中的状态使用对应的语义色。执行时刻采用记录时区，未知时间明确标注，未开始项显示「本次未执行」。耗时四舍五入到秒，非零且不足一秒显示「不到 1 秒」。

点击记录行或用键盘激活任务名称可打开详情，关闭详情后焦点返回标题。重新执行及查看对话各自使用原有权限与可用性判断。操作图标通过 YjIcon 渲染并提供可访问名称。
