# 按钮、筛选项与说明标签尺寸规范

状态：Accepted · 2026-09-08 · 适用：全部活跃 Desktop 页面。

依据用户本轮截图反馈，统一同类组件的高度、字号、内边距、图标与圆角。颜色体系、颜色角色、交互语义和权限边界不变。

## 统一尺寸

| 角色 | 高度 | 文字 | 水平内边距 | 图标 | 圆角 | 实现入口 |
|---|---:|---|---:|---:|---:|---|
| 筛选胶囊、分类、紧凑工具栏操作 | 32px | 14px / 20px 行高 | 12px | 16px，图文间距 8px | 胶囊；普通工具按钮 8px | `yj-control`，胶囊加 `yj-control--pill` |
| 常规按钮、确认弹窗操作 | 36px | 14px / 20px 行高 | 16px | 16px | 8px | `yj-control yj-control--regular`；NButton medium |
| 明确的大操作，如 Chat 发送与附件主入口 | 40px | 14px / 20px 行高 | 16px | 20px | 沿用相应操作的形状 | `yj-control--large`；NButton large |
| 分类、来源、状态等说明标签 | 24px | 12px / 16px 行高 | 8px | 可选，随标签布局 | 6px | `yj-badge`；NTag |
| 数量标签 | 24px，最小宽度 24px | 12px / 16px 行高 | 8px | 无 | 胶囊 | `yj-badge yj-badge--count` |

高度包含边框；胶囊不固定宽度，按完整文案撑开。默认字重 500，已选筛选 600，沿用现有语义色。列表组间距 8px。说明标签不可伪装成操作按钮；静态展示项不因复用几何样式而增加点击、Tab 或 `button` 语义。

树节点、多行权限菜单项、正文内链接、图片预览整面点击区、原生媒体控件和纯图标披露控件属于各自交互类型，不强制拉伸成筛选胶囊。它们的内部小标签或确认按钮仍消费上述对应标准。

## 唯一来源

- `src/styles/variables.css`：32/36/40px 控件高度、24px 标签高度、20/16px 行高。
- `src/styles/component-metrics.css`：只定义几何与排版，不定义任何颜色。
- `src/design/theme/naive-theme.ts`：Naive UI Button/Tag 映射到同一组 tokens；颜色字段完全沿用。
- `YjTabs`：保留键盘、tablist、tab、aria-selected、panel 关联，复用紧凑胶囊。
- 页内颜色和 disabled/hover/selected 仍由现有组件负责；禁止借统一尺寸改变主题或状态色。

## 当前覆盖

| 页面/组件 | 统一内容 |
|---|---|
| 我的店铺 | 三组筛选、场景标签、来源标签；筛选条置于区域标题与说明下方并左对齐 |
| 工作流 | 能力分类、我的工作流分类、创建/排序/视图/查看全部、推荐操作、所有卡片标签 |
| 插件 | 全局 NButton/NTag、区域数量标签；保留已有图标和安装行为 |
| 设置 | 常规操作按钮；资源选择行仍保留独立的多行选择语义 |
| Chat | 权限入口与确认、审批操作、工具身份标签、Artifact 状态标签与操作、图表模式标签、侧栏对话框按钮 |

## 布局要求

- 同一工具栏按同一基线对齐，不混用 32px、40px 的同类筛选。
- 长筛选条可整体置于标题下方；不能靠缩小字号硬塞到标题右侧。
- 重复卡片采用相同内边距和底部对齐；标题允许完整换行，长标题优先均衡换行，不能只剩一个字。
- 至少检查 1180×760 / 1180×728 内容区域、1440×900 及亮暗主题。组件尺寸规范不依赖页面截图缩放比例。
