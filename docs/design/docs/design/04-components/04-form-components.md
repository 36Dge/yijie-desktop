# 表单组件规范


## 文档状态

- 状态：Accepted
- 版本：2.1.0
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义输入、选择、校验、分组、提交和授权配置表单规范。

## 适用范围

适用于 `src/components/yijie/` 下对应组件，以及所有引用这些组件的页面。

## 规范正文

## 表单结构

表单应由标题、说明、字段组、字段说明、错误提示和操作区组成。复杂表单使用分组或步骤，不将大量字段堆在一个卡片中。

定时任务的创建、编辑和草案确认弹窗使用与工作流分类按钮相同的 `--yj-color-border-subtle` 作为字段常态描边。时间面板并排列出小时和分钟，支持方向键、Home 和 End。「仅一次」的运行日期打开月历，支持翻月、方向键选日和回车确认。「今天」按计划时区计算，预览和保存使用所选的本地日期和时间。

弹窗标题使用 18px 小节标题字号，前置日历图标在亮色和暗色主题下均采用纯青柠色底纹和石墨色线条。标题下说明保存后的任务状态和授权要求。管理页取得新建权限后，提前读取本地时区每天 09:00 的原生预览。新建弹窗首帧显示预览标题、时区及已有的有效执行时间。若结果仍在读取，计算提示占据同一行，表单可直接填写。修改时间规则会清除旧时间，保存需等待当前规则的原生预览成功。更多设置收起时摘要显示时区和聊天目标，展开后可编辑。保存、取消和关闭操作始终在弹窗内可见。

## 校验

错误提示必须靠近字段，说明原因和修复方式。不得只提示“格式错误”。

## 敏感字段

Token、密钥、授权信息、Webhook secret 等敏感字段默认隐藏，提供复制、重置、重新授权等明确操作。不得在日志或页面明文展示完整 secret。

本类组件的文字、图标、背景、边界、输入类控件单层 1px 焦点边框、普通容器无阴影与真实浮层轻投影，以 [组件配色与状态矩阵](./09-component-color-state-matrix.md) 为准。readonly 保留正常读值；disabled 只作用于不可用控件；error 与 selected 不能抹掉焦点。现有组件职责、布局与交互不变。

## AI / Codex 必须遵守

- 优先复用现有 `Yj*` 组件，不重复造相同 UI。
- 新组件必须定义 props、slots、状态、空态、错误态和可访问性要求。
- 不允许在业务页面中复制组件内部结构。
- 不允许组件内部硬编码视觉值。

## 实现要求

组件文件使用 PascalCase，例如 `YjMetricCard.vue`。复杂组件应配套 `types.ts`、`README.md` 或文档说明。组件样式使用 token 和 CSS variables。
