# Chat 工作区 Pattern


## 文档状态

- 状态：Accepted
- 版本：1.1.0
- 最后更新：2026-07-30
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义 AI 对话流页面结构。

## 适用范围

适用于对应页面 pattern 的路由页面、业务组件、状态管理、接口接入和文案。

## 规范正文

`/chat` 包含两个互斥页面状态：

1. 新建任务入口态：没有活跃会话时显示。
2. 活跃会话态：已有真实会话时使用完整 Chat 工作区。

### 新建任务入口态

2026-09-10 首页开场更新：以下「开界」规范覆盖历史 FEAT-124 入口态的标题呈现与 placeholder 规则。任务、附件、项目选择等现有能力以活跃代码为准，不退回早期占位入口。

#### 「开界」品牌开场

- `ChatHomeOpening` 在每次进入空白的“新建任务”首页时播放一次，总时长 2200ms；切面出现、空间展开、Logo 成形停留、字标揭示与文案落定。从其他页面或任务会话返回首页会重播，已经在首页时重复点击菜单不重播；已有草稿、附件或错误提示时直接展示静态品牌。
- 标题保持“易界AI”，32px / 40px；描述为“让跨境生意，更进一步。”，14px / 22px。最终 Logo 为 32px，动画峰值为 80px，品牌行 gap 为 12px，描述上间距为 12px，下间距为 32px。现有首页上边距、输入区宽度与交互保留。
- 新任务 placeholder 改为“描述你想完成的事，或添加相关文件…”。继续对话 placeholder 保持原值。功能示例无需在输入区下新增一行。
- 输入、项目选择、审批入口等任何首页操作立即获得响应；动画从当前姿态直接向终态插值，160ms 内收尾，不快放剩余时间线。切页后的标题自动聚焦保留无障碍语义，不触发动画收尾；键盘聚焦输入框或按钮等控件时才收尾。窗口隐藏、开启减少动态效果或组件卸载会取消动画；完成后没有持续 RAF。
- 使用现有 `yijie-mark.svg` 的三个母版路径，每帧把折面透视投影为 SVG 三次贝塞尔曲线；曲线细分后投影以减少透视近似误差。侧壁是连续曲面路径，不使用 CSS 遮罩的逐层位移、低分辨率纹理、Canvas 位图或 CSS 3D 缩放。SVG 保留 `geometricPrecision` 和浏览器抗锯齿；阴影滤镜只作用于椭圆，不能使 Logo 轮廓变糊。动画结束用既有 `YjLogo` 的原始矢量资产呈现。
- 装饰 SVG 不接受指针事件、不进入可访问树；标题及描述保留唯一的原语义 ID。亮暗颜色服从应用 `data-theme`，不读取系统颜色偏好覆盖应用选择。
- 局部 token：`--yj-motion-home-opening` = 2200ms，`--yj-motion-home-opening-settle` = 160ms，`--yj-home-opening-stage-width/height` = 320px / 136px，`--yj-home-opening-logo-peak` = 80px；仅装饰绘制层消费，不扩大页面布局。
- 材质 token：`--yj-home-opening-face` 亮/暗为 `#25282B` / `#FFFFFF`；`edge` 为 `#131619` / `#A5ADB5`；`fold-edge` 两主题为 `#799F30`；`shade` / `light` 为黑 / 白；`shadow` 为石墨 20% / 黑色 48%。仅品牌开场消费；落定为原始纯色 Logo。

`contract-impact = none`：新增首页展示组件和文案，动画随首页挂载播放；Desktop 权限与任务操作、API/Agent Host wire 及本地持久状态均无契约变化。

#### 历史入口态（FEAT-124）

- 页面主标题精确显示“易界AI”。
- 主内容采用居中单列布局，输入区最大宽度遵循 960px 表单布局 token。
- 本次入口态只提供 textarea 的页面内本地输入，不提供发送按钮、附件、店铺上下文、快捷提交、网络请求、持久化或 Agent/Runtime 调用。
- textarea 必须使用稳定的可访问名称“输入你的跨境业务需求”，placeholder 只作示例，不能替代 label。
- 输入为空且未聚焦时，按以下顺序每 4 秒轮换 placeholder：
  1. “搜索热销商品关键词，发现下一个爆款…”
  2. “输入目标市场，获取本地化选品建议…”
  3. “查询物流方案，对比各国时效与运费…”
  4. “粘贴商品链接，一键分析竞品数据…”
  5. “输入店铺名称，诊断运营健康度…”
- 五条文案循环播放；获得焦点或出现输入后暂停，输入为空并失焦后继续。
- 文案切换可使用不超过 160ms 的语义 motion token，不创建 `aria-live` 播报。`prefers-reduced-motion: reduce` 时固定显示第一条，不播放切换动画。
- 文本只存在于当前页面实例内；离开页面或应用重启后清除，且不得进入日志、遥测、URL 或错误上报。

### 活跃会话态

#### FEAT-155 单次执行与独立重跑（4C-3）

立即运行支持当前开启、暂停及已完成计划，执行前明确一次/最长10分钟许可，自动授权和计划状态独立。记录中的重新执行先只读展示原运行与当前已保存配置差异；当前配置无变化也明确创建新运行，旧历史不覆盖。未执行槽不冒充run，已删除计划/失效目标有具体禁用原因；已完成once不因手动动作复活为自动计划。

重跑审阅不准备执行服务，确认时才显式准备并申请本次许可。默认焦点取消，长文本内部滚动，亮暗与1180×760最小窗口/键盘可用。grant与run持稳定请求ID；回执未知只查证或明确原请求重试，不换ID续额；受理、原生终态与业务结果分开，定位新run对应的对话轮次。单次期间自动到点仍按原忙碌跳过规则处理，不排队补跑。

#### FEAT-155 有限自动运行（4C-2）

计划创建后保持暂停。管理卡片的启用/重新确认打开单一确认弹窗，展示内容、运行于、目录语义、Ask、时区与下次时间；默认1次与下次时间后10分钟截止，允许明确调整有限次数/期限，不提供无限授权。截止采用设备时区并显示实际时区名称，下一次时间按计划固定时区展示。默认焦点取消，提交有局部loading；未知保留原请求，只读查证或显式同请求重试，不能自动续额。原生预览变化后重新审阅。

卡片真实区分已启用、暂停/需确认和完成；展示授权到期、额度、未知结果、目标/资源不可用等原因。服务未就绪可显式重新准备，不把管理读取变成启动操作。暂停不会假终止已开始的运行；查看结果沿原运行与对应聊天轮次。仅在App运行且设备清醒时自动执行，正常重开恢复未来，离线不补跑；当前独立重跑、电源和应用内更新不在本批开放。采用既有Naive/Yj组件与2.1.0 tokens，长确认内容内部滚动、亮暗与最小窗口可用。

#### FEAT-155 对话创建定时计划（4B）

管理页“通过对话创建”回到既有新任务输入框，按当前scope一次性预填引导词，等待用户发送。已有输入默认保留，切换需确认；只交接明确输入的文本，不自动复制会话历史、附件或目录。新任务入口的草案模式提示“确认后才会保存”，隐藏普通项目、附件和权限切换操作，使用原ChatComposer和原生聊天展示。

已有会话用途由native的scoped只读查询决定，不能由URL、名称或模型话术推断。普通聊天与受限草案使用各自既有发送路径；缺少用途证据时禁止误发。草案最终结果由native校验，澄清问题和候选摘要使用中文卡片呈现，不要求用户阅读内部JSON。

用户审阅候选时复用管理表单，明确时间/时区及运行目标。模型给出的已有聊天名称只作提示，实际关联必须从授权列表选择。确认仅保存暂停计划，结果不明先按原请求/source查证；重开和刷新不重发。已确认计划可按真实ID返回管理页查看，删除来源不伪造或复活计划。

候选卡在聊天页底部有界滚动，长内容不挤掉输入或确认操作；表单内部滚动，默认安全取消/继续编辑。亮暗主题、1180×760外框及键盘操作保持既有规范。计划执行启用、重跑、唤醒与通知不在4B页面开放。

Chat 工作区由会话列表、消息区、输入区和右侧上下文面板组成。消息区必须区分用户消息、AI 消息、工具调用、审批卡片、结果卡片。输入区支持文本、附件、商品链接、店铺上下文选择。

AI 回答不能只有自然语言，还应在需要时附带结构化结果卡。长任务应转为 Agent 任务流，不在单条消息里无限滚动。

活跃会话态不在 FEAT-124 的实现范围内；不得用入口态本地输入模拟真实会话创建。

## AI / Codex 必须遵守

- 新页面必须先匹配既有 pattern；没有匹配项时先补 pattern 文档。
- 不允许在页面中重新创造布局、状态和交互流程。
- 必须包含 loading、empty、error、permission denied 状态。
- 涉及 Agent 的页面必须展示过程和结果。
- 必须根据是否存在活跃会话选择入口态或会话态，不得同时堆叠两套结构。

## 实现要求

页面文件放在 `src/pages/` 对应业务目录，复杂逻辑进入 `src/domain/` 或 composables。页面只负责组合组件和绑定状态，不承载复杂业务规则。

## 验收清单

- [ ] 页面结构符合 pattern。
- [ ] 主操作明确。
- [ ] 数据和状态完整。
- [ ] 风险/权限/错误已覆盖。
- [ ] 组件复用而非页面堆叠。
- [ ] `/chat` 无活跃会话时只显示入口态，不出现顶部状态、会话列表或右侧面板。
- [ ] 标题、五条 placeholder 顺序、暂停条件和 reduced-motion 行为符合规范。
- [ ] 入口态输入不会产生提交、持久化、网络或日志副作用。
