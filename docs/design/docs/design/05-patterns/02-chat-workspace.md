# Chat 工作区 Pattern


## 文档状态

- 状态：Accepted
- 版本：1.1.0
- 最后更新：2026-07-30
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide

## 目标

适用于对应页面 pattern 的路由页面、业务组件、状态管理、接口接入和文案。

### 首页界獭（2026-10-14）

2026-10-18 启动布局稳定性：新建任务页的本地运行环境检查、阻塞提示与重试入口放在
输入卡片和底部设置栏之后，按实际阅读顺序进入 DOM。检查完成移除提示时，品牌、界獭、
输入卡片和设置栏位置保持不变；不通过延迟显示输入区或关闭动画掩盖位移。
正式对话的状态提示仍在输入区上方，发送条件和恢复行为保持原有逻辑。

`contract-impact = none`：仅调整 Desktop 进程内状态提示布局；Desktop 与 API/Agent Host、
Native IPC 的跨进程交互、权限和本地持久化/重放状态均无可观察变化。

界獭位于新建任务输入卡片的右上沿，面向输入区，保留礼物、青柠围巾与完整尾巴。
显示宽度使用 `--yj-home-mascot-width` 160px，输入区宽度不超过640px时使用128px；
右侧内缩24px（窄宽度16px），接地处与卡片重叠3px。输入区为角色预留96px高度，
包括出现环境状态提示的情况，装饰不能遮盖提示文字或菜单。正式对话及定时任务文本草案不显示。

采用已确认的20秒母版中14.5–18.0秒片段：抱着礼物，放低身体，头靠前爪，闭眼休息。
品牌开场结束后播放一次，停留在实际末帧；同页输入、模型或工作空间切换不重播。
已有草稿、减少动态效果或隐藏窗口进入时只显示睁眼静帧。播放中隐藏窗口时暂停在当前姿态，
返回后继续相邻帧；启用减少动态效果时固定当前姿态并释放动画资源。装饰不可聚焦、忽略指针
事件且对读屏隐藏；初始媒体不可用时保留睁眼静帧，中途不可用时保留当前画面，不妨碍输入与发送。

使用1764×1176无损母版逐帧去背景，统一裁去空白后为1070×594原生像素，24fps、84帧、
单次播放的无损透明素材。没有降采样、插帧、锐化或重新生成角色；只修正透明边缘、保护
白色礼物并按接地线做整数像素平移。毛发内部保留源RGB，背景分离处不能等同原始3D Alpha。
最高显示宽度160px时有超过6倍的源像素密度。浅色与深色界面使用同一素材，只切换轻接触阴影。
详细来源、校验值及导出参数见 `src/assets/mascot/provenance.json`。

2026-10-14 播放修复：原动画WebP在桌面WebView中的实际呈现速度与3.5秒壁钟不一致，
旧计时器会在趴伏尚未完成时强制替换末帧。现将同一84帧无损打包为静态帧图集，用原生分辨率
Canvas逐帧播放，当前图集和后两个图集预解码；上一图集播放完释放。只有实际绘制第84帧才
结束，保持同一个Canvas，不再切换终帧图片。解码延迟、后台恢复及卡顿均不按墙上时间跳帧。
正常目标时长仍约3.5秒，较慢设备允许自然延长；原动画WebP保留作源素材，不在运行时加载。

2026-10-15 悬停反馈：入场实际绘制完成后，鼠标或可悬停笔在角色可见轮廓内停留180ms，
播放一次约6.92秒的「缓慢睁眼→看你片刻→把礼物托近→尾巴轻摆一次→闭眼休息」。
主要睁眼过程约2秒，随后有约1秒真实注视；头继续枕靠前爪，嘴保持闭合。尾根固定，
尾尖峰值约8.2个界面像素（160px角色宽度）；身体持续贴地。离开不打断已经开始的动作，
完成后冷却5秒，并要求重新移出、移入才可再次触发；静止指针不重复触发。
命中使用入场末帧的固定Alpha轮廓，不跟随摆动尾巴改变。组件继续忽略指针事件，
通过被动document监听判断位置；透明留白、输入框、交互控件、菜单和底部重叠区域不触发。
减少动态效果时禁用悬停；后台暂停，返回后续播相邻帧。失败、卸载和中途启用减少动态时
保留最后有效画面，不重播、不突然换姿势。`skipAnimation`仍只用于已有的入场抑制条件。

悬停素材为166帧、24fps、1070×594原生像素的28张无损透明图集，末张有效4帧；
首尾均匹配实际首页Canvas休息帧。首段采用局部眼睑运动重定时与眼区合成，前93帧眼区外
保留原休息帧像素；不以开放眼睛的静帧填充停顿。收抱段经过受限的低频色彩匹配和短接缝
混合，恢复两帧礼物缺失的Alpha及半透明底缘。模型生成的高翘黑尾未采用，改用原睡姿
尾部纹理做受控2.5D局部弯曲，固定尾根且每帧从原纹理重新采样。原像素放大可见短暂的
细毛混合软化及轻微尾部条带纹理；该方式不代表重新生成真实3D毛发。
来源、处理及限制见 `src/assets/mascot/hover/provenance.json`。
图集仍最多同时驻留3张，保持同一Canvas。先在离屏缓冲完成一帧，再整体提交可见Canvas，
避免透明区域清空后下一帧尚未就绪造成闪烁。无声音、文字气泡或新增业务入口。

2026-10-15 后续纠正：用户确认缩短版批准是误触，要求保留完整的缓慢睁眼与注视停顿，
时长可按表演延长。旧3.75秒素材已撤回并归档；上述约6.92秒版本在慢醒、注视、角色、
毛色及Alpha修复审查后替代旧版。历史素材和审查记录保留，不能将原始生成回片的时序
误称为已通过：当前交付明确包含局部运动重定时与后期合成。

`contract-impact = none`：只增加Desktop进程内装饰及媒体资产，不改变API/Agent Host、
Native IPC、权限、跨仓或跨版本交互，也不写入本地持久化或重放状态。
