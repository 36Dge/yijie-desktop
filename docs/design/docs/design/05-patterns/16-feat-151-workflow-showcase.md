## 1. 目标与边界

工作流页为 local demo_fast 交互展示页，帮助跨境电商卖家浏览已有与推荐工作流。页面不代表
工作流引擎、Agent 执行、模板市场或真实数据已经接入。

- 路由固定为 `/workflows`，导航文案为“工作流”，沿用 `workspace` 导航键和 `workspace.use` 权限。
- 只在 exact `local + demo_fast` 展示；public/production 不因本 Feature 自动开放。
- 页面不调用 API、Tauri command、Agent Host、Runtime、数据库或持久化。
- 分类、视图使用单选按钮反馈；新建、查看全部使用可取消的选中反馈；每张推荐卡的演示/执行在卡内互斥选中，再次点击可取消。我的工作流卡片右上角“更多”仅展示，不提供选中状态。
- 排序提供“最近修改 / 最近创建 / 名称排序”，可用鼠标和键盘选择。所有选择仅保存在当前组件内存，离开页面后重置。
- 以上操作不筛选、不重排、不切换卡片布局、不新增内容、不跳转、不执行工作流；原有八张卡片及顺序保持固定。

## 2. 页面结构

页面基于 `YjPage`、`YjPageHeader` 和 `YjSection`，从上到下固定为：

1. 标题“工作流”和说明“集中查看常用自动化流程与推荐方案，工作流方案正在实现中，点击创建工作流按钮。”其中“创建工作流”按用户要求保留青柠文字，使用透明背景，不添加底板或额外内边距。
2. 顶部能力分类：全部、电商获客、批量出图、全网比价、内容创作、视频生成、数据分析、私域运营、更多。
3. “我的工作流”：Workflow 流程图标、六个分类、新建分类、三选项排序、网格/列表切换按钮、标题栏创建入口和四张工作流卡。
4. “推荐工作流”：Route 路径节点图标、查看全部和四张推荐工作流卡。两处区域标题统一通过 YjSection 使用 20px 中性图标、相同间距与对齐方式；不使用星芒图标。

顶部分类按按钮自身宽度使用整行可用空间，仅在放不下下一项时自然换行，不固定为 5+4 或三列；工具条允许换行。我的工作流与推荐工作流使用相同的响应式列数，1268×780 默认窗口、240px 展开侧栏下均显示四列。1180×760 下不得为了
强行保持截图列数而压缩正文、截断关键操作文案或产生主体横向滚动。

## 3. 卡片与信息层级

### 我的工作流卡

- 图标、标题、分类标签、说明和“修改于”时间必须完整可见。
- 卡片右上角“更多”恢复为带可访问名称的展示图标，不进入 Tab 序列，不提供点击选中/按钮悬停效果，不打开菜单；卡片整体仍保留悬停效果。
- 创建工作流置于区域标题右侧，以 32px 虚线边界的紧凑入口表达；点击仅反馈选中，不占据空白卡位、不打开编辑器。
- 卡片图标背景透明，图标使用主题主文字色，保留原有容器尺寸和对齐；分类标签保持中性。

### 推荐工作流卡

- 标题、热门/推荐标签、说明、使用量、演示与执行文案必须完整可见。
- 移除所有推荐卡中的三步流程示意，包括编号、输入/处理/输出标注、节点图标、节点名称与连接箭头；不保留空占位。原有领域常量不因展示区域移除而变更。
- 卡片收敛为顶部标题与标签、中间说明、底部使用量与按钮。最小高度 192px，内边距 20px，内容间隔 16px；标题和说明自然换行，取消各自固定两行的预留高度，同排卡片等高，底部操作统一靠下对齐，窄内容区允许页脚换行。
- 热门/推荐标签保留原有中性底色与次文字颜色，执行主按钮保留青柠。我的工作流卡片图标不使用青柠底板。
- 演示和执行使用带 `aria-pressed` 的按钮，仅切换选中外观，不产生运行结果或成功提示。执行默认使用青柠填充与石墨半粗文字，hover/pressed 使用既有品牌状态色；演示保持中性次按钮，选中时仍为中性灰，始终保持执行的主操作层级。

## 4. 状态与权限

- Idle：由侧栏“工作流”链接进入，不预取数据。
- Loading：不适用；只读本地常量同步加载，不显示虚假骨架屏。
- Success：全部固定内容按截图顺序完整展示。
- Empty：不适用；固定展示集合不为空。
- Error / permission denied：缺少 `workspace.use` 时导航不渲染，深链由 Router guard 在页面实例化前进入无权访问页。
- Retry / Cancel：不适用；页面没有远程请求、提交、执行或长任务。

## 5. 视觉与可访问性

- 颜色、字号、间距、圆角、边框和阴影全部来自现有 token；不建立私有色板。
- 图标只通过 `YjIcon` registry 使用；不得在页面直接 import Lucide。
- 支持系统亮/暗主题；最小窗口为 1180×760。
- 页面有唯一 `h1`，两个主要区域使用 `h2`，卡片使用 `article`，集合使用 `ul/ol`。
- 可操作项使用原生 button/select，按钮以 `aria-pressed` 表达选中；图标按钮提供名称，键盘焦点使用既有中性轮廓。
- 八张卡片统一在 hover / focus-within 显示青柠描边并上移 2px，使用现有 180ms 动效 token，无投影；减少动态效果模式保留描边并取消位移和过渡。卡片本体不新增无意义的 Tab 停靠点。
- axe serious/critical violation 必须为 0。

## 6. 验收清单

- [ ] 导航显示“工作流”，`/workflows`、selected、标题和 `workspace.use` 一致。
- [ ] 九个顶部分类、七个我的工作流分类/新建项和全部工具条文案完整。
- [ ] 创建入口、四张已有工作流卡和四张推荐卡的所有信息与参考截图一致。
- [ ] 分类/视图/排序和其他按钮可点击、可键盘操作；选择独立且卡片内容、顺序、布局不随之改变。
- [ ] 页面内不存在请求、持久化、真实创建/执行或二次跳转。
- [ ] 八张卡片均有悬停/焦点反馈，青柠点缀使用现有 token，减少动态效果模式不位移。
- [ ] light/dark 与 1180×760 无关键重叠、不可达内容或主体横向滚动。
- [ ] 页面语义、无障碍名称和 axe 检查通过。
