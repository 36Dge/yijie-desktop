# 对话文件预览侧栏

状态：需求已接受，local candidate 实施中；真实客户端验收未完成。2026-10-29。

本规范覆盖正式对话内的文件阅读。复用现有文件卡片、附件绑定身份、Native 授权读取和隔离容器。`contract-impact = semantic`：点击文件改为同页阅读，并新增 Desktop 私有预览动作；Runtime、Host、公共契约、持久化结构及旧读取接口不变。

## 布局与入口

进入或返回会话时默认关闭。标题栏按钮展开空白侧栏；点击非图片、视频、SVG 的真实文件引用打开对应内容。草稿附件、普通文本路径和 Markdown 链接不进入本流程。对话与输入框同时缩窄，原对话组件保持挂载。

工作区宽度 W 扣除左导航后计算。W 至少 801 CSS px，分隔线 1px，A=W−1；预览最小 400，最大 `min(1200,floor(0.7*A),A−400)`，默认 `clamp(round(0.6*A),400,max)`。对话宽度为 A−预览宽度。W 不足时收起、提示扩大窗口，保留临时标签，恢复空间后不自动展开。

分隔线命中区 8px。鼠标拖动，左右键每次调整 16px，Shift 为 64px；Home/End 到最小/最大，Enter 或双击恢复默认，Escape/pointercancel 取消本次拖动。窗口变化只夹取显示值，不覆盖手动偏好；复位清除偏好。

## 标签与状态

加号创建空标签，最多 10 个，包括空页。相同真实身份激活已有标签；新文件依次使用当前空页、最右空页、新标签。相同文件名不作为去重依据。满额时保留现状并提示先关闭一个。

标签方向键只移动焦点，Enter/Space 激活，Delete 关闭所聚焦的标签。活动标签关闭后优先右侧再左侧；末页关闭后侧栏保持展开并显示空状态。收起保留同页标签和阅读位置；换会话、权限上下文变化或离页清空。

状态包括空白、加载、正文可读、部分内容、缺失/未就绪/过期/权限不足/不支持/超限/完整性失败，以及可重试的临时失败。等待上限 15 秒包括排队时间，超时撤销展示意图；不能取消的 Native 工作正常收尾，不宣称已经中断底层工作。

空文案：“当前没有文件展示。请尝试在对话流中完成任务，生成一个产物；点击对话中的文件，即可在此预览。”

## 只读内容

标题显示文件名与“只读预览”；阅读控件可翻页、切工作表、缩放。正文允许滚动和选择文字。侧栏没有保存、下载、打印、分享、编辑、发布、系统打开或地址输入。

HTML 保留隔离内联渲染脚本，禁业务控件、导航、表单、下载及外网；DOCX 提供标题、段落、列表、表格及图片，PPTX 按实际关系顺序展示页面正文和图片，XLSX 展示真实单元格、合并区域、共享字符串、日期/百分比及已保存公式结果，PDF 展示系统渲染的实际页面。不是 Office 编辑器或全保真排版；未呈现对象和文本限制必须明示。

仅活动标签持有隔离 Native 内容视图。切换时先隐藏再正常释放；晚到结果不能重新展开侧栏。原文件字节不进入主页面 DOM，Native 同时检查 context、owner/tenant、真实绑定、TTL、摘要与资源预算。图片、视频、SVG 保留原组件路径。

## 视觉与验证

标签条 44px，文件标题行 48px，标签最大 240px，空说明最大 320px，统一由 `--yj-layout-preview-*` 提供。颜色、间距、焦点和图标沿用现有 token 与 YjIcon。左右区独立滚动，菜单/模态层出现或拖动时隐藏 Native 子视图，避免遮挡宿主控件。
