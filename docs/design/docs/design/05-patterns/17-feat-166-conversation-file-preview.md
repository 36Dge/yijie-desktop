# 对话文件预览侧栏

2026-11-06 已在日常开发客户端验收聊天正文的文件链接、路径提示、桌面文档和 HTML 报告侧栏。其余实机范围见「视觉与验证」。

本规范覆盖正式对话内的文件阅读。复用现有文件卡片、附件绑定身份、Native 授权读取和隔离容器。`contract-impact = semantic`：点击文件改为同页阅读，并新增 Desktop 私有预览动作；Runtime、Host、公共契约、持久化结构及旧读取接口不变。

## 布局与入口

进入或返回会话时默认关闭。标题栏按钮展开带“新标签页”的空白侧栏；展开后隐藏对话标题栏的重复入口，收起后恢复入口及键盘焦点。点击助手回复中的文件或报告链接，在右栏打开对应内容。已发送的文档附件沿用绑定身份。草稿附件继续使用输入区预览。对话与输入框同时缩窄，原对话组件保持挂载。

文件预览默认宽度和最小宽度均为 **336 CSS px**。按 1339 × 843 默认窗口、256px 左导航和 100% 缩放计算，扣除 1px 分隔线后，对话宽 746px。输入框两侧各留 32px，边框各占 1px，内部正好为 680px，模型入口仅显示图标。

工作区宽度 W 从左导航右边缘算起。分栏至少需要 737px（预览 336px、分隔线 1px、对话至少 400px）。令 A = W − 1，预览上限为 `min(1200, floor(0.7 * A), A − 400)`。在 1180px 最小窗口，左导航展开时 W 为 924px，默认对话宽 587px。同一会话重新展开或退出全屏会恢复手动设置的宽度，复位回到 336px。

W 与拖动偏好均使用未缩放的 CSS 布局坐标。ResizeObserver 读取 contentRect，首次布局和缩放时读取精确的 computed width，以区分 736.67px 和 737px。鼠标 clientX 位移按视觉宽度与布局宽度之比换算。Native 子视图使用 getBoundingClientRect 窗口坐标。空间不足时收起侧栏并提示扩大窗口，保留标签和手动宽度偏好。恢复空间后由用户重新展开。

空间不足或标签满额提示占用工作区底部独立布局行，聊天输入区与Native预览视口随之收缩；不能悬浮遮挡发送按钮。空间恢复后清除已失效的空间不足提示，保留标签且不自动展开。

分隔线有 8px 命中区，从对话侧延伸到原生阅读区边缘。鼠标停在分隔线上时正文保持可见。拖动过程中，当前阅读视图随宽度调整，保留标签和阅读位置。左右键每次调整 16px，Shift 为 64px。Home/End 到最小/最大，Enter 或双击恢复默认，Escape/pointercancel 取消本次拖动。窗口变化只夹取显示值，不覆盖手动偏好；复位清除偏好。

分隔线正常为1px中性边线；hover及拖动时仍为1px，叠加中段青柠色、上下渐隐的细线，不显示粗outline。青柠色使用 `--yj-color-preview-divider-active`，由品牌色与当前主题文字色混合。键盘焦点另有2px清晰标记，减少动态效果时关闭淡入。

“进入全屏”在应用内容区铺满预览，保留原生标题栏；再次点击“退出全屏”或主界面收到Esc时恢复分栏。有菜单或对话框遮住预览时，Esc先交给该浮层。预览面板移动到应用壳专用容器，原会话、草稿、阅读位置和标签保持挂载；背景导航及聊天区域暂时不可交互。Native预览沿用同一viewId，只通过已有resize同步位置，不重新打开文件。全屏允许在不足分栏宽度时继续阅读；退出时若空间仍不足，收起面板并显示原空间提示。换会话或卸载时释放全屏状态。

本次 `contract-impact = none`：只调整Desktop前端布局、焦点和内存中的展示状态，沿用现有Native预览接口；API/Agent Host、权限、内容读取及本地持久化／重放格式与语义不变。

`contract-impact = semantic`。固定日常开发客户端允许预览对话输出，附件准入继续使用原候选开关。Desktop 私有 `chat-document-preview-v1.schema.json` 增加 `messageFile` 来源。点击后原生端用当前身份核对会话、轮次、助手消息及其确切引用，只读打开系统桌面或该会话工作区内的普通文件。文档与媒体按原生预览类型和大小预算读取。缺失、超限、权限不足和未知格式在右栏显示对应状态。旧的登记产物和附件请求继续按原身份处理。公共 API、Agent Host 和持久化格式沿用现有版本。

## 标签与状态

2026-11-10 用户要求：文档标签图标统一使用彩色实心折角样式，保持 16px。只有文件名、没有 MIME 的本地引用按扩展名选择图标；此推断只用于外观，不参与文件准入。

加号创建空标签，最多 10 个，包括空页。相同真实身份激活已有标签；新文件依次使用当前空页、最右空页、新标签。相同文件名不作为去重依据。满额时保留现状并提示先关闭一个。

标签方向键只移动焦点，Enter/Space 激活，Delete 关闭所聚焦的标签。活动标签关闭后优先右侧再左侧；关闭按钮hover提示“关闭”；末页关闭后收起右侧栏并把焦点还给展开入口。收起保留同页标签和阅读位置；换会话、权限上下文变化或离页清空，重新展开时创建新的空标签。

状态包括空白、加载、正文可读、部分内容、缺失/未就绪/过期/权限不足/不支持/超限/完整性失败，以及可重试的临时失败。等待上限 15 秒包括排队时间，超时撤销展示意图；不能取消的 Native 工作正常收尾，不宣称已经中断底层工作。

空文案：“当前没有文件展示。请尝试在对话流中完成任务，生成一个产物；点击对话中的文件，即可在此预览。”

## 只读内容

文件名显示在活动标签上。有文档时，标签栏下新增固定的 48px 导航栏：左侧为文件名与文件夹图标，右侧为“另存为”图标；空标签不显示。长标题单行省略，保留路径与保存操作。多页文档、多工作表文件以及分段读取的长文档，仅在有其他内容可选时显示相应的阅读控件；正文在导航栏和阅读控件下独立滚动、适配可用宽度。

鼠标移入或键盘聚焦文件夹图标时，浮层显示电脑图标和实际本地文件路径，Escape 关闭。浮层固定在图标上方，按窗口空间选择左／右对齐，禁止翻到原生正文区域；高度限制在可用顶部空间内，长路径可滚动。这样无需隐藏、关闭或重载原生文档，阅读位置保持。

正文文件引用调用原 Native `locate`。登记产物和已发送附件由 Native 先校验身份与 revision，再在该会话已授权工作区内寻找现存文件，核对格式、大小及完整 SHA-256 后返回真实绝对路径。查找有目录层级、条目和读取预算，不全盘扫描，不创建新副本，不以同名或数据库托管类型推断位置。等价副本优先登记名称和较短的稳定路径；没有匹配文件时如实显示无法定位，不展示内部数据库路径或“尚无独立路径”的预设说明。切换文档、版本、会话、授权或关闭预览时清理浮层及旧路径，迟到响应不得显示到新文档。

“另存为”显示同名 tooltip。产物／报告复用既有保存客户端，本地引用与绑定附件通过私有预览协议的 `save` 动作保存原文件。后者仅在 Native 返回 `saveSupported` 后启用，提交原 source 与已预览 revision；默认文件名、内容和目标位置均由 Native 与系统保存窗口确定。等待期间防重复操作，不显示任何保存状态文字。正文阅读仍只读，不增加打印、分享、编辑、发布、系统打开或地址输入。

本轮 `contract-impact = additive`：权威源为 `src-tauri/schemas/chat-document-preview-v1.schema.json`，新增 `save`、对应终态和可选 `saveSupported`。旧操作解释不变；旧客户端可忽略新 metadata，新客户端没有能力字段时不发送新动作。只涉及 Desktop 内部 Native／renderer 配对，不修改公共 API、Host、Runtime、持久化格式或权限范围。源 schema 经现有生成器生成 TypeScript；原生更新需正常退出并通过固定开发入口重开。

同日修复路径查询：私有 schema 为登记产物／绑定附件增加带 revision 的 `locate` 变体和可选 `locationSupported`，仍为 additive。原 messageFile 请求保持；新客户端看到能力字段后才查询受管来源，校验前后使用同一授权与版本，源契约和普通 fixtures 先行并由原生成器同步类型。仅原生端读取受限工作区，renderer 不提交或遍历任意根目录。
