# 对话文件预览侧栏

状态：需求已接受，local candidate 实施中；真实客户端验收未完成。2026-10-29。

本规范覆盖正式对话内的文件阅读。复用现有文件卡片、附件绑定身份、Native 授权读取和隔离容器。`contract-impact = semantic`：点击文件改为同页阅读，并新增 Desktop 私有预览动作；Runtime、Host、公共契约、持久化结构及旧读取接口不变。

## 布局与入口

进入或返回会话时默认关闭。标题栏按钮展开带“新标签页”的空白侧栏；展开后隐藏对话标题栏的重复入口，收起后恢复入口及键盘焦点。点击非图片、视频、SVG 的真实文件引用打开对应内容。草稿附件、普通文本路径和 Markdown 链接不进入本流程。对话与输入框同时缩窄，原对话组件保持挂载。

2026-11-05 按 WorkBuddy 参考及用户追加要求收窄：工作区宽度 W 扣除左导航后计算。W 至少721 CSS px，分隔线1px，A=W−1；预览最小与默认宽度从360px再缩窄40px，均为320px；对话最小400px，最大预览宽度仍为 `min(1200,floor(0.7*A),A−400)`。对话宽度为A−预览宽度。W不足时收起、提示扩大窗口，保留临时标签，恢复空间后不自动展开。

导航为256px时，默认1268px窗口中W=1012，默认预览320、对话691；1180px最小窗口中W=924，默认预览320、对话603。不得按整个窗口或全局阅读列上限计算分栏。手动调整的宽度在同一会话收起、重新展开或退出全屏后保留；复位回到320px。

W与拖动偏好采用未缩放的CSS布局坐标；ResizeObserver读取contentRect，初始及缩放事件读取精确的computed width，不能使用取整clientWidth把720.67误判为721。鼠标clientX位移按实际视觉宽度/布局宽度换算。Native子视图仍消费原getBoundingClientRect窗口坐标，不把布局坐标发给Native。导航、窗口或缩放导致分栏空间不足时收起并保留标签；恢复空间不自动弹开，手动宽度偏好与原会话组件保持。

空间不足或标签满额提示占用工作区底部独立布局行，聊天输入区与Native预览视口随之收缩；不能悬浮遮挡发送按钮。空间恢复后清除已失效的空间不足提示，保留标签且不自动展开。

分隔线命中区 8px。鼠标拖动，左右键每次调整 16px，Shift 为 64px；Home/End 到最小/最大，Enter 或双击恢复默认，Escape/pointercancel 取消本次拖动。窗口变化只夹取显示值，不覆盖手动偏好；复位清除偏好。

分隔线正常为1px中性边线；hover及拖动时仍为1px，叠加中段青柠色、上下渐隐的细线，不显示粗outline。青柠色使用 `--yj-color-preview-divider-active`，由品牌色与当前主题文字色混合。键盘焦点另有2px清晰标记，减少动态效果时关闭淡入。

“进入全屏”在应用内容区铺满预览，保留原生标题栏；再次点击“退出全屏”或主界面收到Esc时恢复分栏。有菜单或对话框遮住预览时，Esc先交给该浮层。预览面板移动到应用壳专用容器，原会话、草稿、阅读位置和标签保持挂载；背景导航及聊天区域暂时不可交互。Native预览沿用同一viewId，只通过已有resize同步位置，不重新打开文件。全屏允许在不足分栏宽度时继续阅读；退出时若空间仍不足，收起面板并显示原空间提示。换会话或卸载时释放全屏状态。

本次 `contract-impact = none`：只调整Desktop前端布局、焦点和内存中的展示状态，沿用现有Native预览接口；API/Agent Host、权限、内容读取及本地持久化／重放格式与语义不变。

## 标签与状态

加号创建空标签，最多 10 个，包括空页。相同真实身份激活已有标签；新文件依次使用当前空页、最右空页、新标签。相同文件名不作为去重依据。满额时保留现状并提示先关闭一个。

标签方向键只移动焦点，Enter/Space 激活，Delete 关闭所聚焦的标签。活动标签关闭后优先右侧再左侧；关闭按钮hover提示“关闭”；末页关闭后收起右侧栏并把焦点还给展开入口。收起保留同页标签和阅读位置；换会话、权限上下文变化或离页清空，重新展开时创建新的空标签。

状态包括空白、加载、正文可读、部分内容、缺失/未就绪/过期/权限不足/不支持/超限/完整性失败，以及可重试的临时失败。等待上限 15 秒包括排队时间，超时撤销展示意图；不能取消的 Native 工作正常收尾，不宣称已经中断底层工作。

空文案：“当前没有文件展示。请尝试在对话流中完成任务，生成一个产物；点击对话中的文件，即可在此预览。”

## 只读内容

标题显示文件名与“只读预览”；阅读控件可翻页、切工作表、缩放。正文允许滚动和选择文字。侧栏没有保存、下载、打印、分享、编辑、发布、系统打开或地址输入。

HTML 保留隔离内联渲染脚本，禁业务控件、导航、表单、下载及外网；DOCX 提供标题、段落、列表、表格及图片，PPTX 按实际关系顺序展示页面正文和图片，XLSX 展示真实单元格、合并区域、共享字符串、日期/百分比及已保存公式结果，PDF 展示系统渲染的实际页面。不是 Office 编辑器或全保真排版；未呈现对象和文本限制必须明示。

仅活动标签持有隔离 Native 内容视图。切换时先隐藏再正常释放；晚到结果不能重新展开侧栏。原文件字节不进入主页面 DOM，Native 同时检查 context、owner/tenant、真实绑定、TTL、摘要与资源预算。图片、视频、SVG 保留原组件路径。

## 视觉与验证

标签条与对话顶部栏共用整体高度：32px导航加32px原生窗口栏，100%缩放下为64px，参考实机WorkBuddy顶部高度；水平留白16px。内部组件在整个顶部区域垂直居中，不再对齐左侧品牌区；文件全屏时左侧额外避让原生窗口按钮。活动标签为32px高的中性圆角底，含文件图标、半粗名称和关闭按钮，标签最小120px、最大240px，多个标签可横向滚动。右侧为“新标签页”“进入全屏／退出全屏”“收起右侧面板”三个32px图标按钮，16px图标、1.5线宽，hover显示对应tooltip。Tooltip优先放在工具栏上方，空间不足时由浮层调整位置；不为原生内容区域之外的提示隐藏文件预览，真正与预览重叠菜单、模态层或拖动仍隐藏Native子视图。

文件标题行48px、空说明最大320px，统一由 `--yj-layout-preview-*` 提供。颜色、间距、焦点和图标沿用现有token与YjIcon。左右区独立滚动。
