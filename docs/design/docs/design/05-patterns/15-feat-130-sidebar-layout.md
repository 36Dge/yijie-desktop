## 1. 主导航顺序

展开态侧栏主区域从上到下固定为：

1. 新建任务
2. 我的店铺
3. 工作流
4. 定时任务
5. 技能
6. 资料库
7. 任务

设置仍固定在侧栏底部。FEAT-151 后“工作流”是 `/workflows` 可用入口，并继续使用既有
`workspace.use` 权限；未开放模块继续使用 disabled 语义，无权限模块在渲染前隐藏。

上方主菜单使用 32px 行高、4px 行间距（2026-11-02 用户调整，原为 36px 行高），导航顶部留白 12px，“任务”前的额外间距为 8px。
字号和图标大小不变，底部设置保留原尺寸，为历史记录释放更多高度。

2026-10-08：侧栏“插件”更名为“技能”，图标使用与对话加号菜单相同的
`skillOperations`（Lucide Wrench）。展开文案、收起态 tooltip 和辅助名称使用同一导航配置；
保留 `/plugins` 路由、`plugin` 导航键和既有权限判断。

2026-10-11：菜单默认文字与每条任务标题统一使用 `--yj-font-weight-regular`（400）
及 `--yj-color-text-primary`；选中菜单按用户补充要求使用 `--yj-font-weight-semibold`（600）。
图标保持 18px，采用与 chatbox
一致的 1.5 线宽；图标与文字间距改为 `--yj-space-2`（8px）。

## 2. 任务记录信息架构

- “任务”是无前置图标的静态分组标题，不是链接、按钮或 disabled 导航项；点击标题不得改变路由。
- 删除 `/tasks` 独立页面、页面布局、导航入口和 lazy route；具体对话继续使用 `/chat/:sessionId`。
- 第一层先展示项目文件夹，第二层为该项目下的对话记录。取消独立折叠箭头，点击文件夹图标、名称或目录按钮内留白即可展开/收起；按钮保留 `aria-expanded`，支持 Enter / Space。右侧“…”菜单独立操作，不切换展开状态。
- 目录内的任务、目录后的独立任务和末尾的已移除目录历史各自按创建时间倒序展示。每组优先展示手动置顶的任务。继续对话或更新执行状态时保留创建顺序。
- 文件夹图标与“任务”标题左侧对齐；目录名称（包括“任务目录”）保留 12px 图文间距，任务树不整体向右缩进。文件夹沿用 18px Lucide 图标，展开与收起线宽均为 1.5；这是用户要求的局部细线变体，其余图标不变。
- 项目被移除后，文件夹消失，其全部历史任务直接显示在“任务”顶层、所有项目文件夹（包括“任务目录”）之后；不生成“项目已移除”或其他占位文件夹。
- 多个已移除项目的历史任务一起平铺在末尾，内部按上述任务排序；置顶或最近更新的已移除项目任务也不越过现存文件夹。分页追加和重新加载遵循相同规则。
- 未选择本地项目的新任务允许发送有效内容，直接显示在“任务”顶层、现存目录之后及已移除项目历史之前，不生成“任务目录”分组；无项目会话详情不展示虚构的本地项目名称。
- 仅改变展示层级，保留每条任务的 sessionId、projectId、标题、状态、置顶信息与权限；历史记录无需迁移，回滚无需修改本地持久数据。API / Agent Host / native IPC 契约和数据格式均不变（contract-impact = none）。仍可用但未列入项目选择器的托管目录继续显示为“任务目录”。
- 点击具体对话后才进入 `/chat/:sessionId` 并加载正文；当前对话条目（目录内或顶层）表达 `aria-current="page"`。
- 只有 `task.read` 时，用户仍可在全局展开侧栏中读取任务记录并选择对话；不恢复独立任务记录页面。
- 只读绑定与选择对话不得调用新建/提交草稿能力；无权执行的项目或对话 mutation 菜单不渲染。

2026-11-02：品牌区下方横线移除，以留白分隔品牌与导航。侧栏展开256px、收起72px，默认窗口尺寸不变。

2026-11-05 侧栏配色：亮色底改为中性浅灰 `#F7F7F7`，暗色底为 `#22262A`，移除侧栏与主内容之间的右侧分割线。灰底延续到上方窗口操作区域，展开、收起及180%/200%缩放时边界与侧栏宽度对齐；内容区继续使用页面背景。导航和任务选中/悬停使用局部 `nav-hover`，普通导航按下使用 `nav-pressed`，原键盘焦点环保留。`contract-impact = none`：仅Desktop样式变化，Desktop/API/Agent Host跨进程交互、权限及本地持久状态无变化。

2026-11-05：按用户纠正，左导航展开宽度恢复256px，收起仍为72px，180%/200%缩放恢复196px适配；缩窄40px针对右侧文件预览面板，默认及最小宽度改为320px。导航文字与图标尺寸保持，历史任务标题按可用宽度截断。

## 3. 滚动与最小窗口

2026-11-18 用户指定的长任务标题：标题超出可用行宽时，鼠标移入任务行或键盘聚焦该任务后，停留500ms再以32 CSS px/s向左循环展示全文，两次标题间隔32px。文字从右侧淡入、向左侧淡出，每侧渐变宽度取16px与标题可用宽度的15%中较小者。移开且失去键盘焦点、打开菜单、操作进行中、重命名或取消溢出时停止并恢复开头/省略显示；减少动态效果时静止。仅活动行测量尺寸并监听布局，卸载时释放监听；UI缩放按CSS布局宽度处理。循环副本对读屏隐藏，任务名称只读一次，不新增标题tooltip。侧栏导航、分组及任务的原字体字号保持，此前对话正文字体规则不受影响。`contract-impact = none`。

2026-11-05 顶部裁切修复：未查看完成任务的读屏说明限定在各自任务行的定位上下文内，不能越过任务树滚动区域撑高应用壳。应用壳及其主体使用不可滚动的裁切容器；滚动只由任务树、业务内容区和对话滚动区承接。定位最新一轮与定时任务指定轮次时，仅修改对话滚动位置，按实际缩放、滚动留白和目标外边距计算对齐，并以 `preventScroll` 恢复目标焦点；不能连带滚动父容器，使品牌、导航和页面标题被裁掉。

`contract-impact = none`：仅修复Desktop进程内滚动与布局；Desktop/API/Agent Host跨进程接口、权限审批、原生执行、路由目标及本地持久状态均不变。

- 主导航项和底部设置保持固定；任务记录树占用侧栏剩余高度。
- 任务记录树自身使用纵向滚动，禁止让长列表推动主导航或设置离开可视区域。
- 左上角窗口操作栏提供唯一侧栏开关，所有页面共用。72px 收起态隐藏“任务”标题与二级树；展开后恢复标题、树及目录展开状态。
- 1180×760 下不得产生侧栏横向滚动或遮挡关键入口。

## 4. 输入区工作空间入口

- 2026-10-03：入口移至输入框下方、权限入口左侧，文案为「选择工作空间」。
- 使用标准紧凑控件：32px 高、14px 文字、16px 图标、8px 圆角；默认透明，中性 hover/pressed。
- 键盘焦点使用 2px 中性 focus-ring。disabled、暗色主题和 reduced-motion 沿用既有 token。
- 已选择时显示名称并用 tooltip 保留长名称全文；已有会话仅展示当前工作空间，不改变只读规则。
- 底部设置行可换行，具体布局以 Chat 工作区 Pattern 的最新补充为准。

本节按设计系统 2.1.0 更新颜色、焦点与分层方式，主导航顺序、树结构、滚动、状态、权限和项目选择行为不变。

## 5. 状态与可访问性

- 侧栏首次读取项目与对话列表时，树内显示“正在读取本地任务…”。列表返回后显示项目、对话或空态。切换到新任务并恢复草稿附件期间，侧栏保留当前列表、目录展开状态和滚动位置。
- Empty：树内显示“暂无任务记录”。
- Error / permission denied：显示稳定中文原因；已有安全元数据可继续浏览。
- 每行在标题右侧预留 16px。最近一轮执行中（`streaming` 或 `inProgress`）时，居中显示从 WorkBuddy 5.11.3 侧栏提取的 `LoadingIconRaw` 六辐图形。图标为 16px，单根辐条含描边总宽 1.7px，每 1.2 秒匀速转一圈。系统启用减少动态效果时显示静态图标。最近一轮为 `completed` 且尚未查看时，同一位置显示 6px 的圆点。图标与圆点在亮暗主题中均为 `#8AC20F`。
- 当前会话随既有事件更新。侧栏可见且有后台任务排队、执行或停止中时，每隔约 3 秒通过现有任务列表读取最新状态，完成后在原行显示未查看圆点。本次展示调整为 `contract-impact = none`，Desktop 继续使用既有列表接口、原生轮次状态和本地查看记录格式。
- 点击左侧任务并成功进入该路由后清除圆点；右键菜单、悬停和仅因路由选中不清除。新一轮排队/运行后重新等待完成提示；运行中点击不提前确认未来的完成。失败、中断、等待审批、空值和未知值不显示。已查看记录按会话/轮次保存在本地普通UI偏好，切页及重开保留，不发送到模型或服务端。
- 每次点击任务（包括重复点击当前任务）都定位到已加载历史的最新一轮起始位置；等待该任务历史完成加载和渲染后定位。定位暂停自动跟随，长回答不被拉至末尾；用户仍可滚动或用回到底部按钮继续跟随。导航取消不清除提示、不触发定位。带具体 `turn` 的原有深链继续定位指定轮次，侧栏点击则移除该定位参数并回到最新一轮。
- 任务按钮以标题作为名称，按状态关联“任务执行中”或“任务已完成，尚未查看”的读屏说明。
- 定时执行以运行记录绑定的会话 ID 和本地轮次 ID 定位任务行。新轮次开始时自动展示任务行并展开对应目录一次。执行中使用六辐旋转图标，完成未读使用绿色圆点，查看后清除圆点。标题右侧只展示图形，完整状态通过读屏说明传达。状态观察复用现有只读接口。此次展示的 `contract-impact = none`。
- 此次本地UI偏好为 `contract-impact = additive`，schema、兼容/回滚及状态来源见仓库 `docs/chat-reading-preference.md`。
- 自动运行和本地轮次提交后，Native 在投递之前向主窗口发送 `yijie://scheduled-run-created-v1`。这个 Desktop 私有通知只有 `{"schemaVersion":1}`，`contract-impact = additive`。侧栏收到后立即按当前权限读取运行记录与对应轮次，并在启动阶段短暂复查。旧版组合和未收到通知的窗口沿用周期读取。调度、授权与历史格式继续使用各自原有契约。
- 后台元数据先到达时，侧栏核对同一轮次，一起更新任务行与状态图标。管理页根据真实运行变化重新读取当前筛选、排序下已加载的页，单次任务结束后显示「已完成」并移除旧的下次执行时间。
- 对话选中态与 `YjNavItem` 一致：`control-hover` 中性底、`radius-md` 圆角，不显示青柠侧边条。2026-11-03 移除任务行`:active`的额外加深色：悬停、普通按下、右键打开菜单均保持同一hover背景，当前任务的常驻选中底仍保留。键盘焦点与选中态可以同时表达。
- 移除对话行的“更多”按钮；右击任意有操作权限的任务（包括未打开的任务），在指针处显示既有重命名、置顶、永久删除菜单，同时屏蔽WebView原生菜单。整行留白、标题及置顶图标均属于右键命中范围。没有操作权限或操作中也不回落到系统文字菜单。
- 任务行使用标准及WebKit的 `user-select: none`，并阻止 `selectstart`，避免拖选/双击选中标题。只清除该任务标题范围内的旧选区，不影响对话正文复制及重命名输入框的编辑。macOS Control-click与右键相同，不触发普通导航或已查看确认。
- 同一时间只显示一个任务/项目菜单。任务菜单与项目菜单共用现有反向缩放浮层，定位消费实际指针坐标，菜单内容按UI比例放大，避免120%/200%坐标重复缩放与底部裁切。键盘聚焦任务后可用 Shift+F10 或菜单键打开，方向键选择、Enter 执行、Escape 关闭；Tab 关闭菜单并继续焦点导航。
- 菜单选项继续按真实权限过滤；切换对话、权限变化或操作执行时关闭。重命名和置顶明确使用右击任务的sessionId，复用既有Native命令，不切换当前正文。永久删除弹窗最大宽度 420px，标题 18px、字重 600；正文里的任务名最多显示 20 个字符，超出以“…”收尾，始终保留不可撤销提示，不展示内部清理细节。确认后按完整 sessionId 核对目标再删除；导航取消或目标变化时不执行删除。取消弹窗后焦点回到触发任务行。
- 常规删除在后台自动检查结果，不显示进度卡，也不再读取正删除任务的问题或回答回执。只有确认删除结果后才移除对话；实际失败、结果未确认且需要手动检查、仅本地记录已删除等情况仍提供相应提示。此调整为 `contract-impact = none`：不改变 Desktop 与 API / Agent Host 的接口、权限、删除语义或本地持久状态格式。
- 2026-11-02 本次修复 `contract-impact = none`：仅调整Desktop事件处理、文字选择与内部操作目标参数。Native/API/Agent Host wire、权限、会话/查看持久状态格式及模型调用不变。
- 2026-10-03：项目与“任务目录”均提供“…”、右键、Shift+F10/菜单键入口，提供置顶/取消置顶及移除。
  托管目录使用本地侧栏偏好保存排序和移除状态；移除后会话平铺到侧栏末尾，不删除文件、不停止定时任务。
  用户项目继续使用原生操作，托管目录不会调用普通项目移除接口。偏好不可读或保存失败时不提交操作，并显示错误。
  此补充的 `contract-impact = additive`，新 UI 偏好键的格式及升级/回滚说明见仓库 `docs/task-directory-menu-audit.md`。
- 静态任务记录标题不设置 `aria-disabled` 或 `aria-current`；具体对话负责当前页语义。
