# FEAT-130 主导航与任务记录 Pattern

## 文档状态

- 状态：Accepted
- 版本：2.1.0
- 最后更新：2026-09-26
- 适用 Feature：`FEAT-130`、`FEAT-151`
- 适用仓库：`yijie-desktop`
- Contract impact：`none`

本文由段成威在 FEAT-130 需求中确认，取代 `01-app-shell-navigation.md` 与
`12-feat-126-chat-app-shell-candidate.md` 中关于主导航顺序、`/tasks` 独立页面和 Chat 项目树挂载位置的冲突段落。
其余导航、Chat、安全、权限、主题与可访问性规范继续有效。

## 1. 主导航顺序

展开态侧栏主区域从上到下固定为：

1. 新建任务
2. 我的店铺
3. 工作流
4. 定时任务
5. 插件
6. 资料库
7. 任务记录

设置仍固定在侧栏底部。FEAT-151 后“工作流”是 `/workflows` 可用入口，并继续使用既有
`workspace.use` 权限；未开放模块继续使用 disabled 语义，无权限模块在渲染前隐藏。

上方六个菜单使用 36px 行高、4px 行间距，导航顶部留白 12px，“任务记录”前的额外间距为 8px。
字号和图标大小不变，底部设置保留原尺寸，为历史记录释放更多高度。

## 2. 任务记录信息架构

- “任务记录”是静态分组标题，不是链接、按钮或 disabled 导航项；点击标题不得改变路由。
- 删除 `/tasks` 独立页面、页面布局、导航入口和 lazy route；具体对话继续使用 `/chat/:sessionId`。
- 第一层先展示项目文件夹，第二层为该项目下的对话记录。取消独立折叠箭头，点击文件夹图标、名称或目录按钮内留白即可展开/收起；按钮保留 `aria-expanded`，支持 Enter / Space。右侧“…”菜单独立操作，不切换展开状态。
- 目录名称（包括“任务目录”）与“任务记录”标题文字左对齐，文件夹图标与标题图标共用 18px 尺寸及 12px 图文间距；任务树不再整体向右缩进。
- 项目被移除后，文件夹消失，其全部历史任务直接显示在“任务记录”顶层、所有项目文件夹（包括“任务目录”）之后；不生成“项目已移除”或其他占位文件夹。
- 多个已移除项目的历史任务一起平铺在末尾，内部沿用原任务列表排序；置顶或最近更新的已移除项目任务也不越过现存文件夹。分页追加和重新加载遵循相同规则。
- 未选择本地项目的新任务允许发送有效内容，直接显示在“任务记录”顶层、现存目录之后及已移除项目历史之前，不生成“任务目录”分组；无项目会话详情不展示虚构的本地项目名称。
- 仅改变展示层级，保留每条任务的 sessionId、projectId、标题、状态、置顶信息与权限；历史记录无需迁移，回滚无需修改本地持久数据。API / Agent Host / native IPC 契约和数据格式均不变（contract-impact = none）。仍可用但未列入项目选择器的托管目录继续显示为“任务目录”。
- 点击具体对话后才进入 `/chat/:sessionId` 并加载正文；当前对话条目（目录内或顶层）表达 `aria-current="page"`。
- 只有 `task.read` 时，用户仍可在全局展开侧栏中读取任务记录并选择对话；不恢复独立任务记录页面。
- 只读绑定与选择对话不得调用新建/提交草稿能力；无权执行的项目或对话 mutation 菜单不渲染。

## 3. 滚动与最小窗口

- 主导航项和底部设置保持固定；任务记录树占用侧栏剩余高度。
- 任务记录树自身使用纵向滚动，禁止让长列表推动主导航或设置离开可视区域。
- 左上角窗口操作栏提供唯一侧栏开关，所有页面共用。72px 收起态隐藏二级树，只保留任务记录图标与完整辅助名称；展开后恢复树及目录展开状态。
- 1180×760 下不得产生侧栏横向滚动或遮挡关键入口。

## 4. 主页项目选择条

- 仅主页新建任务 composer 上方的项目选择条圆角由 `--yj-radius-md` 提升为
  `--yj-radius-lg`，即从 8px 增加到 12px。
- 未 hover 状态使用结构背景 token：亮色项目条与页面均为纯白，以现有间距、标签和细中性边框建立可辨认边界；不再要求 app/page 的填色差。
- hover 使用局部 `--yj-color-control-hover`，边框按 control-hover；键盘焦点使用 2px 中性 focus-ring。disabled、暗色主题和
  reduced-motion 行为沿用现有规范。
- 不硬编码颜色或圆角，不改变活跃会话中的只读项目条。

本节按设计系统 2.1.0 更新颜色、焦点与分层方式，主导航顺序、树结构、滚动、状态、权限和项目选择行为不变。

## 5. 状态与可访问性

- Loading：树内显示“正在读取本地任务…”，主导航不移动。
- Empty：树内显示“暂无任务记录”。
- Error / permission denied：显示稳定中文原因；已有安全元数据可继续浏览。
- 对话菜单、项目菜单、确认弹窗与键盘焦点继续复用现有 `ChatSidebarTree` 行为。
- 静态任务记录标题不设置 `aria-disabled` 或 `aria-current`；具体对话负责当前页语义。

## 6. 验收清单

- [ ] 主导航七项顺序与本文一致，资料库位于任务记录之前。
- [ ] 任务记录标题不导航，应用不存在 `/tasks` 页面或路由。
- [ ] 现存项目为第一层、对话为第二层；移除项目后历史任务平铺在顶层末尾，无占位目录，刷新和分页后保持顺序。
- [ ] 长列表只在任务记录区域滚动，顶部导航与底部设置保持可见。
- [ ] 新建任务项目选择条保留 12px 圆角，纯白默认态的结构边界与 hover/focus 明确。
- [ ] 亮色、暗色、1180×760、200% zoom、键盘与 reduced-motion 检查通过。
