# 主题与暗色模式规范


## 文档状态

- 状态：Accepted
- 版本：2.1.0
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界亮色、暗色和跟随系统主题的行为。

## 适用范围

适用于全局主题、Naive UI、ECharts、图标、代码块、表格和弹层。

## 规范正文

## 默认策略

易界默认主题为**跟随系统**。

用户设置中可以提供三种选项：

1. 跟随系统。
2. 亮色。
3. 暗色。

## 主题状态来源

主题状态由 `theme.store.ts` 或等价 store 管理，并持久化到本地安全或普通偏好设置中。

## 亮色主题要求

- 使用 **A「清爽青柠」＋01「纯白通透」**。
- App、页面、导航、卡片、弹层和通用弱背景全部为纯白 `#FFFFFF`。
- 主要文字为石墨 `#25282B`，主操作填充为青柠 `#C3F35B`，主操作文字与图标为石墨。
- 空间分区通过留白、既有间距和细边框建立；不能恢复灰色或绿灰色的大面积底色。
- 普通选中控件不消费浅绿 soft；导航原底 + 3px 青柠标记，小筛选实色青柠。普通文字、图标、链接与焦点均中性。

## 暗色主题要求

暗色延续石墨、青柠品牌关系，以中性石墨分层，不采用深绿色背景，也不机械反相亮色主题。

| 语义 | 暗色值 |
|---|---|
| App / 页面 / 导航 | `#191C20` |
| 卡片 / 输入区 | `#25282B` |
| 弹层 | `#2E3237` |
| 通用内嵌区 | `#22262A` |
| 主 / 正文 / 次 / 元信息 | `#F5F7FA` / `#E6E9ED` / `#C2C7CE` / `#969EA8` |
| 弱 / 默认 / 强边框 | `#30363D` / `#414850` / `#69717B` |
| 主操作 / 主操作文字 | `#C3F35B` / `#25282B` |
| 导航选中 / 普通操作文字 / 焦点 | 原导航底 + 3px 青柠 / `#F5F7FA` / 2px `#F5F7FA` |
| 控件轮廓 / hover 或浮层输入轮廓 | `#6A727C` / `#969EA8` |

- 两个主题使用同一青柠主色，hover / active 分别为 `#D0F780` / `#B1E343`。
- 主操作始终使用石墨字；暗色不能因全局浅色文字继承而变成白字青柠。Checkbox / Radio 的选中标记、Switch 滑块及轨道内文字、当前分页和 checked Tag 同样使用石墨。
- 导航选中、Tabs 和 Select 选中文字使用各主题正常 `text-primary`；亮色为石墨，暗色为浅色，不能统一继承青柠填充色作为细字或图标。
- 普通卡片与输入无阴影；焦点为 2px 中性清晰色环，无模糊/glow。真实浮层使用 `0 6px 20px rgba(0,0,0,.28)`。
- 图表保留既有状态与多系列语义，暗色首色替换为青柠，亮色细线与数据点首色使用 `#4B651D`；文字、坐标与 tooltip 同步切换为中性石墨体系。
- Logo 选择已批准的 SVG 暗色或反白资产，青柠折面保留品牌色；不得用 CSS filter 反转图片。
- 禁用文字只用于不可用控件；审批原因、错误说明和空态文字仍使用正常文本 token。

## 主题切换

主题切换使用 120ms–180ms 过渡，不做夸张动画。切换不应重置页面状态、表单状态或 Agent 任务状态。

## AI / Codex 必须遵守

- 不允许只实现亮色主题。
- 不允许用 CSS filter 反转图标或 logo 代替暗色适配。
- 不允许主题切换导致路由刷新或任务中断。
- 不允许图表在暗色下使用不可读颜色。

## 实现要求

规范参考实现位于 `exports/src/styles/variables.css`、`exports/src/design/theme/naive-theme.ts` 和 `exports/src/design/theme/echarts-theme.ts`。后续迁移时，主题状态集中到活跃应用的统一 store；组件不得自行判断系统主题。

切换时先设置根元素的 `data-theme` 与相应 `color-scheme`，再读取解析后的 CSS token，更新 Naive UI 的基础 light / dark theme 和 `themeOverrides`，并同步 ECharts 与 SVG Logo 变体。只改 CSS 而不更新组件库基础主题，不能视为暗色适配完成。

2.1.0 的组件配色规则同时用于规范、参考导出和活跃页面颜色收敛；偏好持久化与主题切换行为不变。不得从源码改动推断所有运行态都已验收，具体范围以验证记录为准。

状态优先级与 readonly/disabled、selected+focus、error+focus 的完整组合见 [组件配色与状态矩阵](../04-components/09-component-color-state-matrix.md)。

## 验收清单

- [ ] 默认跟随系统。
- [ ] 用户可以切换主题。
- [ ] Naive UI 和 ECharts 同步主题。
- [ ] 切换不丢失页面状态。
- [ ] 暗色下对比度可读，主操作保持青柠底石墨字。
- [ ] 亮色背景为纯白，暗色背景为中性石墨，没有绿色大面积染底。
- [ ] 亮暗主题的 SVG Logo、表格、弹层与焦点状态一致适配。
