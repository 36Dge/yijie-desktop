# 配色与品牌预览

组件配色规范 **2.1.0** · A「清爽青柠」＋01「纯白通透」。以下样张直接使用 `exports` 中的颜色 tokens、Naive UI 主题和 SVG 组件。

亮色背景、导航和卡片均为纯白，用留白与细边框建立层级。暗色使用中性石墨分层；正文、普通图标与焦点为中性，青柠主按钮配石墨文字。普通卡片/输入无阴影，焦点为2px无glow。
