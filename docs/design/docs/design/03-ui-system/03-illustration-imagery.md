# 插画与图片规范


## 文档状态

- 状态：Accepted
- 版本：2.0.0
- 最后更新：2026-09-05
- 适用仓库：`yijie-desktop`
- 适用技术栈：Tauri v2、Vue 3、Vite、TypeScript、Pinia、Vue Router、Naive UI、ECharts、Lucide
- 默认语言：中文

## 目标

定义易界插画、空态图、说明图和图片使用规则。

## 适用范围

适用于空态、欢迎页、引导页、插件市场、授权引导、错误页和产品说明页。

## 规范正文

易界插画风格为**线性插画**。

## 风格规则

- 线性为主，使用 1.5px–2px 线宽。
- 颜色使用青柠点缀 + 石墨线条 + 纯白留白，少量状态色只表达对应状态；暗色按主题适配线条与背景。
- 形状清爽，不使用重拟物和 3D。
- 插画用于解释，不用于装饰堆叠。
- 空态插画优先与具体任务相关，例如店铺授权、物流追踪、Listing 诊断。

## 图片规则

- 平台截图、商品图、店铺数据图必须来自用户授权或 mock 数据。
- 文档示例不得使用真实卖家敏感数据。
- 未授权图片不得提交到仓库。

## 空态插画场景

- 未连接店铺。
- 暂无任务。
- 暂无插件。
- 数据同步中。
- 检索结果为空。
- 网络或平台 API 失败。

## AI / Codex 必须遵守

- 不允许生成 3D 插画。
- 不允许用卡通人物作为核心空态风格。
- 不允许使用未知版权图片。
- 不允许在插画里出现真实平台后台截图，除非明确授权。
- 不允许让插画比任务文案更抢眼。

## 实现要求

插画资产放入 `src/assets/illustrations/`，文件名使用场景语义。空态组件通过 `YjEmpty` 统一展示插画、标题、说明和操作。

## 验收清单

- [ ] 插画为线性风格。
- [ ] 颜色符合 token。
- [ ] 图片来源可追溯。
- [ ] 空态包含明确下一步操作。
- [ ] 不含真实敏感数据。
