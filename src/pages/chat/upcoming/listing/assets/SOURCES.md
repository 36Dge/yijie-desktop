## 报告口径

两份报告均为 2026-11-27 的本地示例。Amazon 的五个章节取自用户提供的全景分析报告，分析对象换为指定毛衣。TK 的六个章节取自用户提供的 FastMoss 报告截图，分析对象换为指定面霜。

- Amazon 商品参数、展示价、关联变体评论样本、月销量估算及反查词量参考 Sorftime 美国站。针织衫比价样本使用 B0F9L1CYF7、B0D9RR2Y9K、B08D6GJMH1。访问意图和评论主题分布为构造数据，卖点矩阵是编辑示例。
- TK 商品与同类保湿品的 90 天销量、展示价和内容覆盖参考 FastMoss 美国站。对标商品 ID 为 1731583840101438362、1731070777705009503、1729722480591933882 和 1730755770838979038。价格带按五款样本各自的起售价计算。
- TK 关键词机会指数由示例搜索量除以匹配商品数计算。示例周曲线的七个数据点合计 11,121 件。Amazon 跨平台参考词量来自 Sorftime 美国站 2026-11-25 快照。
