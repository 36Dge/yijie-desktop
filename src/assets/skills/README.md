# Skill 图标资产

2026-10-18 按用户要求，使用 Codex 内置 `image_gen` 分别生成 38 个技能图标与 5 个分类图标。

初版依据用户提供的产品截图，使用浅彩色底板和饱和色实心主体。每个图案均依据本地目录中的技能名称与能力描述原创绘制。

2026-11-18 使用内置 `image_gen` 为全部 38 项内置技能制作微型立体物件图标。每个物件对应技能的具体用途，例如供应商评估用验货章、竞品分析用样品天平、跨境营销文案用打字机、PPC 广告管理用扩音器、发票生成用票据计算器。透明原图按物件轮廓居中，导出为统一浅灰底的 192×192 PNG，在 48px 卡片图标内保留约 28–31px 的物件长边。

- `generated/` 存放 PNG 图像，客户端通过显式导入选择素材，并通过 CSS 设置圆角。
- `generation-prompts.json`：逐项技能信息、意象、配色和完整生成提示词。
- `provenance.json`：内置工具原始输出位置、原图与发布素材 SHA-256、尺寸和派生处理。
- `../../icons/skill-artwork.ts` 按稳定技能 ID 选择图像。后续新增且尚无专属图像的内置技能使用本分类的代表物件，个人导入技能使用通用手册。

卡片图像显示为 48×48，名称文字提供可访问语义。分类标题显示名称和技能数量。亮暗主题共用素材，普通按钮与状态图标沿用现有组件。
