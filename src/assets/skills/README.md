# Skill 图标资产

2026-10-18 按用户要求，使用 Codex 内置 `image_gen` 分别生成 38 个技能图标与 5 个分类图标。

参考为用户提供的产品截图：浅彩色应用底板、饱和色主体、小尺寸下清楚的实心意象。每个技能的主题来自当前本地目录的名称和能力描述；所有图案为原创语义图形，不复制参考产品或电商平台的官方标志。

- `generated/`：随客户端打包的 PNG 图像，应用通过 CSS 设置圆角。
- `generation-prompts.json`：逐项技能信息、意象、配色和完整生成提示词。
- `provenance.json`：内置工具原始输出位置、原图与发布素材 SHA-256、尺寸和派生处理。
- `../../icons/skill-artwork.ts`：稳定技能 ID 与分类映射。未知技能回退同分类图像。

卡片显示 48×48，分类显示 24×24；图像装饰性显示，名称文字提供完整可访问语义。亮暗主题共用素材。普通按钮与状态图标沿用现有组件，不把图像路径加入 Native、Agent Host 或持久化契约。
