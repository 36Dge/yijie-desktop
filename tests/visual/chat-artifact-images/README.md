# 图片产物浏览器验收页

复用已运行的开发前端，在浏览器打开：

`http://localhost:1420/tests/visual/chat-artifact-images/index.html`

页面挂载真实 ChatArtifactList / ChatArtifactImage / ChatAnswerActions 和应用主题、toast。图片来自普通本地合成 SVG；客户端只有内存调用计数，原生复制和保存须在易界开发客户端另行验证。

“检查布局”读取浏览器的真实几何，要求图片、预览按钮、定位框同宽同高；更多按钮距图片右上角各 8 CSS px、位于图片内；图片保持宽高比，最长边不超过 440 CSS px。界面缩放采用应用的同一组 ui-zoom helper。

建议在 1180×760 视口执行：

1. 五种图片比例分别配合 80%、100%、120%、160%、200% 缩放检查布局。
2. 切换窄列、长标题和暗色，再检查同一矩阵。
3. 切换多图，确认每个菜单跟随自己的图片。
4. 鼠标打开菜单后按方向键/Esc；打开大图后用 Tab/Shift+Tab、加减号、0、拖动和刷新。
5. 200% 下关注菜单和 tooltip 坐标，确保没有重复缩放或移出窗口。
6. 切换生成、传输、失败、取消、过期状态，确认占位、文案和操作能力正确。

修复前的横图基准：图片 440×247.5、定位框 760×247.5，右内距 -312。修复后的基准：图片与定位框均为 440×247.5，右/上内距均为 8。

单元测试不负责浏览器几何计算；本页保留了可重复的布局断言，结果直接显示在页面底部。
