# 多任务媒体验收页

在仓库根目录生成普通本地素材：

```sh
node tests/visual/chat-artifact-videos/generate-fixtures.mjs
```

脚本使用已安装的 ffmpeg，生成三种颜色的 12 秒无音频 H.264 视频和对应 PNG，位于忽略目录 `.local/media-stress-20261114/`。
已有文件不覆盖；不使用真实用户数据或攻击性素材。

使用已运行的开发前端打开：

`http://127.0.0.1:1420/tests/visual/chat-artifact-videos/index.html`

外层固定 1180×760；也可直接打开 `frame.html` 并设置浏览器视口。
如果没有运行前端，可单独使用 `pnpm dev --host 127.0.0.1`，完成后用 Vite 的 `q + Enter` 正常退出。

页面挂载真实 ChatArtifactList、图片与视频组件。六个任务具有不同的会话/轮次/产物身份，但使用相同文件名；
红、蓝、绿画面必须与所选任务匹配。8.7 MB 为布局测试元数据；客户端是内存实现，不能替代原生授权和保存检查。

- 首次依次查看六项后，反复切换任务，观察各项读取次数是否保持不变。
- 视频打开后关闭，观察“正在播放”变为 0，播放器 paused=true，currentTime 停止增长；重开应沿用有效播放器。
- 三视频超过两个句柄时旧播放器会淘汰，封面仍保留；返回旧封面不读取，点击播放才按需准备播放器。
- 勾选“暂缓读取”可保持普通读取 Promise 等待。主动刷新后，旧图片/封面应保持可见；关闭重开不追加请求。
- 用“完成待处理读取”或 F8 完成等待；弹窗内可直接按 F8，无须点击已忙碌的刷新按钮。
- 暂缓首个读取后快速经过其他任务，再完成等待：已经离开的普通排队任务应跳过，最终选定任务正确呈现。
- 检查亮/暗、窄列、长标题以及 100%/200% 缩放；关闭动画过程中不应先出现空白弹窗。

播放状态来自实际 DOM 媒体元素，不通过测试脚本主动改写 paused/currentTime。
刷新浏览器会清空本页缓存与计数。所有控制只作用于验收页，不修改日常对话。
